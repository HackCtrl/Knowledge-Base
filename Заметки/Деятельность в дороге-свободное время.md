Для проверки безопасности («вайб-кодинга», созданного ИИ-агентами) на GitHub ключевым встроенным инструментом выступает [GitHub Advanced Security (GHAS)](https://github.com/security/advanced-security/code-security) со сканированием кода через **CodeQL** и функцией **Copilot Autofix**, которая автоматически закрывает найденные уязвимости с помощью ИИ. [[1](https://github.com/security/advanced-security/code-security), [2](https://github.com/security/advanced-security/code-security)]

Встроенные инструменты GitHub

- **Code Scanning (CodeQL):** Анализирует потоки данных в коде и ищет уязвимости (например, SQL-инъекции), которые часто допускают нейросети.

- **Copilot Autofix:** Создает контекстные ИИ-исправления для обнаруженных ошибок безопасности прямо в интерфейсе пулл-реквеста.

- **Dependabot:** Находит уязвимости в сторонних библиотеках и пакетах, которые массово подключают ИИ-ассистенты, и автоматически предлагает обновить их.

- **Secret Scanning:** Блокирует случайную публикацию секретных ключей, API-токенов и паролей, часто захардкоженных ИИ в коде. [[1](https://www.microsoft.com/en-us/securityengineering/sdl/ghas), [2](https://docs.github.com/ru/code-security/concepts/code-scanning/code-scanning), [3](https://teamdynamix.umich.edu/TDClient/47/LSAPortal/KB/PrintArticle?ID=13191), [4](https://www.youtube.com/watch?v=FK_WUFzmp7g), [5](https://github.com/security/advanced-security/code-security), [6](https://github.com/security/advanced-security/code-security)]

Специализированные ИИ-скрипты и скиллы для вайб-кодинга

- **Vibe Security Skill / GuardVibe:** Наборы промптов и правил для ИИ-агентов (Cursor, Claude Code), которые интегрируют правила безопасности (OWASP) прямо во время генерации кода.

- **Vibe-Security-Scanner:** Скилл для ИИ-агентов, выполняющий локальный аудит архитектуры и уязвимостей перед коммитом в репозиторий. [[1](https://github.com/funky-monkey/vibecoding-security-scanner), [2](https://github.com/goklab/guardvibe), [3](https://github.com/raroque/vibe-security-skill)]
