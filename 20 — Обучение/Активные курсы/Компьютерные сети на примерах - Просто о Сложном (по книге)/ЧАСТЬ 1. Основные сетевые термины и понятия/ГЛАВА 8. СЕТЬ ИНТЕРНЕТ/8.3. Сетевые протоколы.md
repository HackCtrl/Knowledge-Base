- ***Интернет протокол IP*** - он обеспечивает схему адресации и механизм маршрутизации, которые позволяют передавать данные от одного устройства к другому через Интернет 
- ***Протокол управления передачей (TCP)*** - работает совместно с IP для обеспечения надежной доставки данных. Он разбивает данные на пакеты, отправляет их через Интернет, а затем собирает их на принимающей стороне 
- ***UDP*** - похож на TCP, но используется там где скорость важнее надежности 
- ***Протокол передачи гипертекста (HTTP)*** - используется веб-браузерами и серверами для передачи гипертекстовых (HTML) документов через Интернет 
- ***Протокол передачи файлов (FTP)*** - используется для передачи файлов между устройствами 
- ***Простой протокол передачи почты (SMTP)*** - используется для отправки сообщений электронной почты 
- ***POP и IMAP*** - используются почтовыми клиентами для получения сообщений электронной почты с сервера
