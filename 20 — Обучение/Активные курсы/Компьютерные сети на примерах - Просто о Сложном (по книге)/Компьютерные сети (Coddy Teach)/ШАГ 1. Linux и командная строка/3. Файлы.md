`touch` - команда используется, чтобы создать новый пустой файл в текущем каталоге 
- `touch hello.txt`

**Создание нескольких файлов одновременно:**
```bash
touch file1.txt file2.txt file3.txt
```

**Создание файла внутри папки:**
```bash
touch documents/notes.txt
```

`cat` - команда, чтобы прочитать и отобразить содержимое файлов 
```bash
cat readme.txt
```

- `head` - отобразит только **first 10 lines**
- `tail` - отображает **последние 10 строк**
- `-n` - сколько строк показывать 

```bash
head -n 5 readme.txt   # показать первые 5 строк
tail -n 3 readme.txt   # показать последние 3 строки
```

- `less` - открывает файл в прокручиваемом просмотрщике
