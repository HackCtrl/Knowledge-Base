***Терминал*** — это мощный текстовый интерфейс, который позволяет напрямую общаться с операционной системой вашего компьютера

`echo "Hello World!"` - echo для вывода текста или переменных на экран

**Команда терминала имеет следующую структуру:** 
- ```bash
command "argument"
```

- `command` - программа, которую мы хотим запустить (`echo`)
- `argument` - входные данные, которые мы передает команде (`"Hello World"`)

***Комментарии*** — это строки в скрипте оболочки, которые оболочка игнорирует. Их используют, чтобы добавлять к коду заметки и пояснения для людей

**Пример комментария:** 
```python
# Это комментарий
```

***Строка шебанга*** - специальный комментарий в верхней строке, говорит системе какую оболочку использовать 

```python
#!/bin/bash
echo "This script runs with Bash"
```
