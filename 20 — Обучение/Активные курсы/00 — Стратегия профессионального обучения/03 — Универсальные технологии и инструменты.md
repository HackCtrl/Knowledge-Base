# Универсальные технологии и инструменты

## Принцип отбора

Инструмент не является учебным направлением и не получает собственного приоритета. Он используется только тогда, когда конкретный урок или ближайший практический результат одного из пяти курсов без него невозможен.

## Допустимо внутри текущего задания

| Инструмент | Где допускается | Зачем | Граница |
|---|---|---|---|
| Wireshark | Сетевая лабораторная или анализ события в активном курсе | Проверить путь пакета и поля протокола | Не изучать как отдельный курс; использовать только нужные фильтры |
| Сетевые команды ОС | Конкретная задача диагностики сети | Проверить адрес, маршрут, DNS и соединение | Фиксировать только команды, необходимые для текущего сценария |
| KQL и учебный Elastic Stack | Практика курса по противодействию кибератакам | Проверить гипотезу по учебным событиям | Не добавлять второй SIEM и не превращать KQL в отдельный курс |
| Инструмент официального стенда ViPNet | Только экзаменационный трек | Выполнить операцию из подтверждённой программы | Не считать действие освоенным без разрешённого доступа и подходящей версии |

## Использовать по необходимости

| Инструмент или группа | Для чего | Когда подключать | Минимальный результат |
|---|---|---|---|
| `ping`, `tracert`/`traceroute`, `nslookup`/`dig`, `netstat`/`ss` | Базовая диагностика доступности, маршрута, DNS и соединений | Только в соответствующем сетевом кейсе | Карточка диагностики с объяснением выбора команды |
| PowerShell | Безопасные повторяемые проверки служб, процессов, файлов и событий | Только когда этого требует текущая тема ИБ, администрирования или 1С | Короткий проверенный скрипт на учебной машине |
| tcpdump | Захват трафика без графического интерфейса | На Linux-этапе курса ИБ | Короткий захват и перенос в Wireshark для анализа |
| Nmap | Инвентаризация разрешённого учебного стенда | После сетевого фундамента и только на собственных узлах | Список сервисов учебной VM и объяснение ограничений сканирования |
| Windows Firewall и iptables/nftables | Разрешающие и запрещающие правила | Сегментация, ViPNet-аналоги, hardening | Два правила и проверка разрешённого/запрещённого трафика |
| OpenSSL | Сертификаты, ключи и базовая PKI | При подготовке ViPNet и повторении криптографии | Учебный сертификат, проверка полей и схема доверия |
| Docker | Быстрое развёртывание существующей лаборатории | Только если конкретная лабораторная уже использует контейнер | Один контейнер, журнал и описание сетевого подключения |
| Регулярные выражения | Поиск и нормализация строк | Минимальный скриптинг, PowerShell, анализ журналов | Один шаблон на обезличенном журнале с тестами |
| Базовая работа с API | Получение структурированных данных | Только если это требуется существующей лабораторной | Безопасный запрос к учебному или открытому API и проверка ошибки |

## Минимальный скриптинг без отдельного курса

[[Python для кибербезопасности — содержание]] сохранён как справочный источник, но исключён из активной нагрузки. Для текущих целей достаточно:

1. понимать назначение небольшого скрипта;
2. читать базовую структуру кода;
3. безопасно изменять параметры, не меняя непонятную логику;
4. запускать код только в тестовой среде;
5. проверять входные данные, результат и сообщения об ошибках;
6. использовать ИИ для подготовки заготовки, но самостоятельно проверять команды и последствия;
7. не запускать непроверенный код в рабочей инфраструктуре.

> [!warning] Граница навыка
> Выполненные Python-задачи подтверждают учебную практику, но не означают освоение Python как самостоятельной компетенции. Скриптинг считается встроенным инструментом системного администрирования и кибербезопасности.

## Отложить

| Инструмент или тема | Почему отложить | Когда вернуться |
|---|---|---|
| Полный Kali Linux как отдельное направление | Создаст большой набор инструментов без текущей задачи | Только под конкретную легальную лабораторную существующего курса |
| Proxmox | Сейчас достаточно одного локального гипервизора | Когда появится задача постоянного домашнего стенда |
| Одновременное изучение VMware, VirtualBox и Hyper-V | Дублирование функций и высокая стоимость переключения | Выбирать по требованиям конкретной лаборатории |
| Kubernetes | Слишком большой слой относительно текущих целей | После уверенного Docker и реальной потребности существующего материала |
| Глубокая PKI | Требует криптографического и инфраструктурного фундамента | После уточнения программы ViPNet |
| Продвинутое Active Directory | Рабочий опыт ограничен вводом компьютеров в домен; полномочия не подтверждены | После систематизации Windows, пользователей, групп и GPO |
| Полное администрирование MikroTik | Подтверждена только базовая работа | После сетевого курса и при наличии легального учебного стенда |
| Дополнительные SIEM | Уже есть Elastic Stack и KQL | Только если существующий курс требует другой продукт |
| UserGate | Не входит в окончательный состав | Не возвращать без отдельного решения владельца |
| OPNsense | Не входит в окончательный состав | Допустим только как готовое средство конкретной лабораторной активного курса |
| MikroTik CHR | Не входит в окончательный состав | Допустим только как готовое средство конкретной сетевой лабораторной |

## Правило против «зоопарка»

1. Инструмент появляется только внутри задачи курса.
2. Для него создаётся один результат, а не отдельная дорожная карта.
3. Инструмент не создаёт новую очередь задач и не учитывается как курс.
4. UserGate, OPNsense и MikroTik CHR не возвращаются в активный план автоматически.
