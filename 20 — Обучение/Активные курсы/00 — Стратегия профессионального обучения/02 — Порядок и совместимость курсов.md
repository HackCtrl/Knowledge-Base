# Порядок и совместимость курсов

## Модель нагрузки

> [!important] Ограничение параллельности
> В каждый момент времени: **один основной курс + один ограниченный параллельный курс**. Инструмент применяется только внутри конкретного урока или практики. ViPNet занимает отдельный временный экзаменационный слот `P0` до экзамена.

## Отдельный экзаменационный трек

ViPNet не является этапом постоянной дорожной карты. До экзамена он ведётся параллельно короткими контрольными точками из [[04 — Стратегия подготовки по ViPNet]]. После экзамена выполняется обязательное действие **«Пересмотреть после экзамена»**: оставить материал справочником, отложить или продолжить только при новой подтверждённой необходимости.

ViPNet не заменяет основной курс. Если экзамен не имеет подтверждённого ближайшего срока, его объём ограничивается одним коротким занятием между основными контрольными точками.

## Роль 1С в маршруте

1С подключается после короткой контрольной точки SQL. Для перехода не требуется завершать весь SQL: достаточно самостоятельно применять `SELECT`, `WHERE`, `NULL`, `CASE` и `JOIN`. После этого 1С занимает единственный параллельный слот, пока не выполнена объединённая задача по текущему синтаксическому блоку.

## Роль SQL

- SQL занимает единственный параллельный слот до контрольной серии из пяти запросов.
- После контрольной точки SQL используется прикладно для 1С, отчётов, анализа данных и будущих задач ИБ.
- План не включает администрирование СУБД как отдельную специализацию.

## Учебный режим

Актуальная заметка с недельным планом чтения и повторения существует, но не имеет даты и подтверждённого статуса. Поэтому стратегия использует занятия и контрольные точки, а не дни недели.

### Минимальный режим — 15–25 минут

- повторить одну связанную группу заметок;
- ответить на один содержательный вопрос;
- исправить одну ошибку в предыдущем задании;
- обновить собственный вывод;
- выполнить одну короткую команду или проверку.

**Результат занятия:** один абзац своими словами, исправленная задача или короткая запись о пробеле.

### Основной режим — 45–90 минут

1. Один учебный блок без переключения между курсами.
2. Краткий конспект только новых идей.
3. Одно практическое действие.
4. Проверка результата.
5. Собственный вывод и следующее действие.

**Результат занятия:** законченная заметка или небольшой проверяемый артефакт.

### Расширенный режим — свободный выходной

1. Повторить предварительные знания.
2. Изучить один крупный блок.
3. Выполнить лабораторную.
4. Разобрать ошибку или альтернативный сценарий.
5. Оформить доказательство навыка.
6. Связать результат с работой или другим курсом.

**Результат занятия:** лабораторная или кейс, который можно воспроизвести после перерыва.

## Правила переноса знаний

- из сетей в ViPNet: адресация, маршрутизация, сегментация, диагностика и анализ трафика;
- из DevOps в кибербезопасность: Linux, журналы, контейнеры, БД и мониторинг;
- из курса ИБ в противодействие: модель атаки, источники телеметрии и защитные меры;
- из справочных Python-задач в анализ событий: чтение структуры кода, парсинг строк, JSON и XML без возобновления курса;
- из SQL в SIEM и 1С: фильтрация, даты, связи таблиц и проверка данных;
- граница SQL и 1С: общий SQL развивает реляционное мышление, а язык запросов 1С работает с метаданными, регистрами, виртуальными таблицами и синтаксисом платформы; прямой SQL к рабочей базе не является целью плана;
- из рабочего сопровождения 1С в обучение: реальные пользовательские сценарии без рабочих данных;
- из Jira и Confluence в обучение: понятная фиксация симптомов, действий, результата и вывода.

## Когда переходить дальше

- не ждать максимального уровня по каждой теме;
- для сетевого этапа требуется самостоятельная диагностика одного безопасного сценария;
- для 1С — самостоятельная объединённая BSL-задача;
- для курса ИБ — один законченный защитный кейс;
- для противодействия — самостоятельный запрос и объяснение результата;
- для ViPNet — требования экзамена и выполнение уникальных операций на разрешённом стенде.
