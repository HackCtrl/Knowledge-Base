# Повторение курса «1С программирование для начинающих»: введение и основы синтаксиса

Эта заметка помогает вернуться к курсу после перерыва. Она охватывает весь пройденный материал: информационную базу и конфигурацию, режимы работы 1С, файлы `DT` и `CF`, первую программу, переменные, типы данных, условия, циклы и структуры.

> [!tip] Как повторять

> 2. После каждого раздела ответь на вопросы «Проверь себя» своими словами.

> 5. Заверши итоговым тестом и чек-листом готовности.

> [!important] О примерах кода
> Примеры в этой заметке приведены в нормализованном виде. В исходных учебных решениях встречаются опечатки и незавершённые конструкции; сами конспекты сохранены без изменений, а типичные ошибки собраны в отдельном разделе ниже.

## 1. Платформа, конфигурация и информационная база

### Платформа и прикладное решение

**Платформа 1С:Предприятие** — программная среда, которая запускает прикладные решения и предоставляет инструменты разработки, хранения данных и администрирования.

**Конфигурация** — описание прикладного решения: его объектов, интерфейса, форм, модулей и алгоритмов. Именно конфигурацию изменяет разработчик.

**Информационная база** — рабочая среда конкретного прикладного решения. Она объединяет конфигурацию, пользовательские данные и служебную информацию, необходимую системе.

Упрощённая связь:

```text
Платформа 1С
  запускает
Информационную базу
  внутри которой находятся
Конфигурация + пользовательские данные
```

### Два режима работы

| Режим | Для кого | Основные задачи |
|---|---|---|
| **1С:Предприятие** | Пользователь | Ввод и изменение данных, выполнение операций, формирование отчётов |
| **Конфигуратор** | Разработчик и администратор | Изменение конфигурации, написание кода, обновление базы, отладка, выгрузка и загрузка |

Код курса пишется в **Конфигураторе**, а его результат обычно проверяется в режиме **1С:Предприятие**.

### Файлы `DT` и `CF`

| Формат | Что содержит | Для чего нужен |
|---|---|---|
| `.dt` | Информационную базу целиком: конфигурацию и данные | Резервная копия, перенос или восстановление учебной базы |
| `.cf` | Конфигурацию без пользовательских данных | Перенос структуры прикладного решения или сохранение конфигурации |

Основные команды:

- `Администрирование → Выгрузить информационную базу` — создать файл `DT`;
- `Администрирование → Загрузить информационную базу` — восстановить базу из `DT`;
- `Конфигурация → Сохранить конфигурацию в файл` — создать файл `CF`;
- `Конфигурация → Загрузить конфигурацию из файла` — загрузить конфигурацию из `CF`.

> [!warning] Восстановление базы
> Загрузка `DT` перезаписывает текущее состояние информационной базы. Выполняй такие действия только в учебной базе или после создания проверенной резервной копии.

## 2. Первая программа и базовый синтаксис

### Где пишется код

В пройденном примере используется **модуль приложения**. Он открывается в Конфигураторе через меню конфигурации.

После изменения кода:

1. обнови конфигурацию базы данных клавишей `F7`;
2. запусти приложение для отладки клавишей `F5`;
3. проверь результат в режиме 1С:Предприятие.

### Вывод сообщения пользователю

```bsl
Сообщение = Новый СообщениеПользователю;
Сообщение.Текст = "Привет, мир!";
Сообщение.Сообщить();
```

Разбор примера:

- `Сообщение` — переменная;
- `Новый СообщениеПользователю` — создание объекта;
- `Текст` — свойство объекта;
- `Сообщить()` — метод объекта;
- `;` — разделитель операторов.

### Переменные

**Переменная** — именованное место для временного хранения значения во время выполнения программы.

Хорошие имена:

```bsl
ИмяПользователя = "Анна";
КоличествоПопыток = 3;
ДокументПроведен = Истина;
```

Правила имени:

- первый символ — буква или знак подчёркивания;
- далее можно использовать буквы, цифры и знак подчёркивания;
- пробелы в имени недопустимы;
- имя должно объяснять смысл значения.

### Комментарии

Однострочный комментарий начинается с `//`:

```bsl
КоличествоПопыток = 3; // Допустимое число попыток входа
```

## 3. Основные типы данных и выражения

### Простые типы

| Тип | Пример | Что хранит |
|---|---|---|
| Строка | `"Привет"` | Текст |
| Число | `1250.50` | Целое или дробное число |
| Булево | `Истина`, `Ложь` | Логическое значение |
| Дата | `'20261015123000'` | Дату и при необходимости время |

```bsl
Наименование = "Клавиатура";
Количество = 5;
Цена = 2499.90;
ЕстьНаСкладе = Истина;
ДатаПоступления = '20261015';
```

Дата в литерале записывается в порядке `ГГГГММДД`, а при наличии времени — `ГГГГММДДччммсс`.

Также дату можно создать функцией:

```bsl
ДатаПоступления = Дата(2026, 10, 15);
```

### Арифметические операции

```bsl
Сумма = 10 + 5;
Разность = 10 - 5;
Произведение = 10 * 5;
Частное = 10 / 5;
```

Для строк оператор `+` выполняет объединение:

```bsl
Имя = "Анна";
Приветствие = "Здравствуйте, " + Имя + "!";
```

При объединении текста с числом полезно явно преобразовать число в строку:

```bsl
Количество = 5;
Текст = "Количество: " + Строка(Количество);
```

### Работа с датой

Число при сложении с датой или вычитании из даты задаёт количество секунд:

```bsl
ДатаНачала = Дата(2026, 10, 15);
СекундВСутках = 24 * 60 * 60;
ДатаЗаДеньДоНачала = ДатаНачала - СекундВСутках;
```

Разность двух дат позволяет получить интервал в секундах:

```bsl
ДатаНачала = Дата(2026, 10, 15);
ДатаОкончания = Дата(2026, 10, 20);
ИнтервалВСекундах = ДатаОкончания - ДатаНачала;
КоличествоДней = ИнтервалВСекундах / (24 * 60 * 60);
```

### Функция `Формат()`

`Формат()` меняет представление значения, но не обязательно само исходное значение.

```bsl
Цена = 274.1948;
ЦенаДляВывода = Формат(Цена, "ЧДЦ=2");

ДатаСобытия = '20261015123000';
ДатаДляВывода = Формат(ДатаСобытия, "ДФ='дд.ММ.гггг ЧЧ:мм'");
```

Пример вывода нескольких значений:

```bsl
Сообщение = Новый СообщениеПользователю;
Сообщение.Текст = "Товар: " + Наименование
	+ Символы.ПС + "Количество: " + Строка(Количество)
	+ Символы.ПС + "Цена: " + Формат(Цена, "ЧДЦ=2");
Сообщение.Сообщить();
```

## 4. Условный оператор и логические выражения

### Простое условие

```bsl
Если Условие Тогда
	// Код выполняется, если условие равно Истина
КонецЕсли;
```

Пример:

```bsl
ОстатокНаСкладе = 7;

Если ОстатокНаСкладе > 0 Тогда
	Сообщение = Новый СообщениеПользователю;
	Сообщение.Текст = "Товар есть на складе";
	Сообщение.Сообщить();
КонецЕсли;
```

### Ветви `ИначеЕсли` и `Иначе`

```bsl
Если Условие1 Тогда
	// Первая ветвь
ИначеЕсли Условие2 Тогда
	// Вторая ветвь
Иначе
	// Ни одно условие выше не выполнилось
КонецЕсли;
```

Выполняется только первая подходящая ветвь. После неё программа выходит из конструкции `Если`.

```bsl
ОстатокНаСкладе = 7;

Если ОстатокНаСкладе = 0 Тогда
	Статус = "Нет в наличии";
ИначеЕсли ОстатокНаСкладе < 5 Тогда
	Статус = "Заканчивается";
Иначе
	Статус = "В наличии";
КонецЕсли;
```

### Операции сравнения

| Оператор | Смысл |
|---|---|
| `=` | равно |
| `<>` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

### Логические операторы

- `И` — все объединённые условия должны быть истинны;
- `ИЛИ` — достаточно одного истинного условия;
- `НЕ` — меняет логическое значение на противоположное.

```bsl
ДокументПроведен = Истина;
СуммаДокумента = 12500;
ИННКонтрагента = "0000000000";

Если ДокументПроведен
	И СуммаДокумента >= 10000
	И ИННКонтрагента <> "" Тогда

	РезультатПроверки = "Документ прошёл проверку";
Иначе
	РезультатПроверки = "Нужно проверить реквизиты документа";
КонецЕсли;
```

### Тернарный оператор

Тернарный оператор выбирает одно из двух значений:

```bsl
Результат = ?(Условие, ЗначениеЕслиИстина, ЗначениеЕслиЛожь);
```

```bsl
ОстатокНаСкладе = 0;
Статус = ?(ОстатокНаСкладе > 0, "В наличии", "Под заказ");
```

Он удобен для короткого выбора значения, но длинную бизнес-логику понятнее оформлять обычной конструкцией `Если`.

### Порядок условий

Условия проверяются сверху вниз. Сначала размещай более конкретные случаи, затем общие:

```bsl
Возраст = 17;

Если Возраст < 16 Тогда
	Категория = "Не допущен";
ИначеЕсли Возраст < 18 Тогда
	Категория = "Юниор";
Иначе
	Категория = "Взрослый";
КонецЕсли;
```

Если первым поставить условие `Возраст > 16`, оно перехватит почти все последующие варианты и часть ветвей никогда не выполнится.

### Проверь себя

1. Когда выполняется блок после `Иначе`?
2. Сколько ветвей одной конструкции `Если` может выполниться за один проход?
3. Чем `И` отличается от `ИЛИ`?
4. Что делает `НЕ`?
5. Как записывается «не равно»?
6. Когда тернарный оператор удобнее обычного `Если`?
7. Почему важен порядок ветвей `ИначеЕсли`?

## 5. Циклы

**Цикл** повторяет блок кода, пока действует заданное правило.

### Цикл `Пока`

```bsl
Пока Условие Цикл
	// Повторяемый код
КонецЦикла;
```

```bsl
Счетчик = 1;

Пока Счетчик <= 5 Цикл
	Сообщение = Новый СообщениеПользователю;
	Сообщение.Текст = Счетчик;
	Сообщение.Сообщить();

	Счетчик = Счетчик + 1;
КонецЦикла;
```

В цикле `Пока` обязательно проверь:

1. начальное значение управляющей переменной;
2. условие продолжения;
3. изменение переменной внутри цикла.

Если значение не изменяется, цикл может стать бесконечным.

### Цикл `Для`

```bsl
Для Счетчик = НачальноеЗначение По КонечноеЗначение Цикл
	// Повторяемый код
КонецЦикла;
```

```bsl
Для Счетчик = 1 По 5 Цикл
	Сообщение = Новый СообщениеПользователю;
	Сообщение.Текст = Счетчик;
	Сообщение.Сообщить();
КонецЦикла;
```

`Для` удобен, когда количество повторений известно заранее. `Пока` удобен, когда завершение зависит от условия.

### Обратный порядок

```bsl
Для Счетчик = 1 По 9 Цикл
	ЧислоВОбратномПорядке = 10 - Счетчик;
	Сообщить(ЧислоВОбратномПорядке);
КонецЦикла;
```

### Вложенные циклы

Вложенный цикл полностью выполняется для каждого шага внешнего цикла:

```bsl
Для ПервыйМножитель = 1 По 9 Цикл
	Для ВторойМножитель = 1 По 9 Цикл
		Результат = ПервыйМножитель * ВторойМножитель;
		Сообщить(Строка(ПервыйМножитель)
			+ " * " + Строка(ВторойМножитель)
			+ " = " + Строка(Результат));
	КонецЦикла;
КонецЦикла;
```

### Цикл `Для каждого`

Он используется для перебора элементов коллекции:

```bsl
Для Каждого Элемент Из Коллекция Цикл
	// Работа с текущим элементом
КонецЦикла;
```

Этот вид цикла применяется далее при работе со структурой.

### Проверь себя

1. Когда лучше использовать `Пока`, а когда `Для`?
2. Из каких трёх частей складывается безопасный цикл `Пока`?
3. Почему цикл может стать бесконечным?
4. Как вывести числа от 9 до 1 с помощью цикла `Для`?
5. Сколько раз выполнится внутренний цикл из 9 шагов при 9 шагах внешнего цикла?
6. Для чего нужен цикл `Для каждого`?

## 6. Структуры

**Структура** хранит связанные значения в виде пар `Ключ → Значение`.

Пример:

```text
Наименование → Клавиатура
Количество   → 5
Цена         → 2499.90
```

### Требования к ключу

- ключ уникален внутри одной структуры;
- начинается с буквы или знака подчёркивания;
- может содержать буквы, цифры и знак подчёркивания;
- не содержит пробелов.

### Создание и заполнение

```bsl
Товар = Новый Структура;
Товар.Вставить("Наименование", "Клавиатура");
Товар.Вставить("Количество", 5);
Товар.Вставить("Цена", 2499.90);
```

Структуру можно создать с заранее указанными ключами:

```bsl
Товар = Новый Структура("Наименование, Количество, Цена");
Товар.Наименование = "Клавиатура";
Товар.Количество = 5;
Товар.Цена = 2499.90;
```

### Получение значений

```bsl
НазваниеТовара = Товар.Наименование;
ЦенаТовара = Товар["Цена"];
```

### Фиксированная структура

```bsl
ФиксированныеДанныеТовара = Новый ФиксированнаяСтруктура(Товар);
```

Фиксированная структура создаётся на основе обычной структуры и используется, когда набор значений после создания не должен изменяться.

### Перебор элементов

```bsl
Для Каждого ЭлементСтруктуры Из Товар Цикл
	Сообщить(ЭлементСтруктуры.Ключ
		+ ": " + Строка(ЭлементСтруктуры.Значение));
КонецЦикла;
```

Каждый элемент при переборе предоставляет ключ и соответствующее значение.

### Проверь себя

1. Какую задачу решает структура?
2. Почему ключи должны быть уникальными?

## 7. Как темы соединяются в одной задаче

Рассмотрим параметры учебного документа:

```bsl
Документ = Новый Структура;
Документ.Вставить("Номер", "000001");
Документ.Вставить("Сумма", 12500);
Документ.Вставить("Проведен", Истина);
Документ.Вставить("КонтрагентЗаполнен", Истина);
```

Проверим данные условием:

```bsl
Если Документ.Проведен
	И Документ.Сумма >= 10000
	И Документ.КонтрагентЗаполнен Тогда

	СтатусПроверки = "Документ готов к обработке";
Иначе
	СтатусПроверки = "Документ требует проверки";
КонецЕсли;
```

Выведем параметры циклом:

```bsl
Для Каждого Параметр Из Документ Цикл
	Сообщить(Параметр.Ключ + ": " + Строка(Параметр.Значение));
КонецЦикла;

Сообщить(СтатусПроверки);
```

В одной задаче используются:

- строки, числа и булевы значения;
- структура для объединения параметров;
- условный оператор для проверки;
- логический оператор `И`;
- цикл `Для каждого` для вывода данных;
- преобразование значения функцией `Строка()`.

Если ты можешь объяснить каждую строку этого примера, основные темы курса связались в единую картину.

## 8. Практический минимум после перерыва

### Задание 1. Безопасно сохранить учебную базу

В учебной информационной базе:

1. создай резервную копию `DT`;
2. отдельно сохрани конфигурацию в `CF`;
3. объясни, чем будут отличаться эти два файла;
4. не загружай их обратно без необходимости.

### Задание 2. Повторить переменные и типы

Создай переменные:

- `НазваниеКурса` — строка;
- `КоличествоУроков` — число;
- `КурсАктивен` — булево значение;
- `ДатаПовторения` — дата.

Выведи их одним сообщением, каждое значение с новой строки.

> [!success]- Один из вариантов решения
> ```bsl
> НазваниеКурса = "1С программирование для начинающих";
> КоличествоУроков = 13;
> КурсАктивен = Истина;
> ДатаПовторения = Дата(2026, 10, 15);
>
> ТекстСообщения = "Курс: " + НазваниеКурса
> 	+ Символы.ПС + "Уроков: " + Строка(КоличествоУроков)
> 	+ Символы.ПС + "Активен: " + Формат(КурсАктивен, "БЛ=Нет; БИ=Да")
> 	+ Символы.ПС + "Повторение: " + Формат(ДатаПовторения, "ДФ='дд.ММ.гггг'");
>
> Сообщить(ТекстСообщения);
> ```

### Задание 3. Проверить остаток

По значению `ОстатокНаСкладе` определи статус:

- `0` — «Нет в наличии»;
- от `1` до `4` — «Заканчивается»;
- `5` и больше — «В наличии»;
- отрицательное число — «Ошибка остатка».

> [!success]- Один из вариантов решения
> ```bsl
> ОстатокНаСкладе = 3;
>
> Если ОстатокНаСкладе < 0 Тогда
> 	Статус = "Ошибка остатка";
> ИначеЕсли ОстатокНаСкладе = 0 Тогда
> 	Статус = "Нет в наличии";
> ИначеЕсли ОстатокНаСкладе < 5 Тогда
> 	Статус = "Заканчивается";
> Иначе
> 	Статус = "В наличии";
> КонецЕсли;
>
> Сообщить(Статус);
> ```

### Задание 4. Повторить циклы

1. Циклом `Для` выведи числа от 1 до 10.
2. Циклом `Пока` выведи числа от 10 до 1.
3. Вложенными циклами выведи таблицу умножения от 1 до 5.

> [!success]- Ориентиры
> - В `Для` границы задаются конструкцией `От ... По ...`.
> - В `Пока` начальное значение равно `10`, условие — `Счетчик >= 1`, изменение — `Счетчик = Счетчик - 1`.
> - Для таблицы умножения внешний цикл отвечает за первый множитель, внутренний — за второй.

### Задание 5. Собрать данные в структуру

Создай структуру `Сотрудник` с ключами:

- `Имя`;
- `Должность`;
- `Активен`;
- `ДатаПриема`.

Заполни безопасными учебными значениями и выведи все элементы циклом `Для каждого`.

> [!success]- Один из вариантов решения
> ```bsl
> Сотрудник = Новый Структура("Имя, Должность, Активен, ДатаПриема");
> Сотрудник.Имя = "Учебный пользователь";
> Сотрудник.Должность = "Стажёр";
> Сотрудник.Активен = Истина;
> Сотрудник.ДатаПриема = Дата(2026, 10, 15);
>
> Для Каждого Реквизит Из Сотрудник Цикл
> 	Сообщить(Реквизит.Ключ + ": " + Строка(Реквизит.Значение));
> КонецЦикла;
> ```

## 9. Типичные ошибки, которые нельзя закреплять

- Объект называется `СообщениеПользователю`, а логическое значение — `Ложь`; опечатка в имени приводит к ошибке.
- Присваивание нескольких значений свойству `Сообщение.Текст` без промежуточного `Сообщить()` оставит только последнее значение.
- Ветвь записывается как `Иначе`, без числа или дополнительного выражения после неё.
- Конструкции завершаются словами `КонецЕсли;` и `КонецЦикла;`.
- В цикле `Пока` должна изменяться именно та переменная, которая участвует в условии.
- Слишком общее первое условие может сделать следующие ветви `ИначеЕсли` недостижимыми.
- Для объединения текста с числами и другими значениями безопаснее использовать явное преобразование `Строка()` или `Формат()`.
- `DT` и `CF` нельзя считать одинаковыми резервными копиями: `DT` содержит базу целиком, `CF` — конфигурацию.
- Загрузка `DT` перезаписывает текущую учебную базу.
- Арифметика даты с числом выполняется в секундах; сутки — это `24 * 60 * 60`.
- Ключ структуры не должен содержать пробелы и должен быть уникальным.
- Персональные данные из учебных примеров не следует переносить в публичные заметки; используй нейтральные тестовые значения.
