### **Дистрибутивы Windows**

***Дистрибутив*** - это программный пакет, который содержит ОС и дополнительные программы, необходимые для ее установки и работы на компьютере

***Клиентский дистрибутив*** - предназначенная для установки на персональные компьютеры конечных пользователей 

***Серверный дистрибутив*** - разработанная для установки на сервер. Представляют собой сетевые сервисы, такие как веб-хостинг, управление БД, ФС и другие, и поддерживают большую нагрузку и большое количество одновременных подключений 

### **Разрядность Windows** 

***Разрядность ОС*** - указывает на способ обработки данных и объем памяти, который система может использовать

### **Файловая система** 

***Файловая система*** - это метод и структура организации, хранения и управления данными на носителе информации, таком как жесткий диск, флешка или SSD. Файловая система определяет, как файлы и данные организованы, какие имена им присваиваются и как осуществляется доступ к ним. В операционной системе Windows используются различные ФС, каждая из которых имеет свои особенности и преимущества и ограничения

### **Иерархия директорий в Windows** 

***Иерархия*** - где файлы и папки расположены в виде древовидной структуры 

***Том*** - это логическая единица хранения данных на физическом диске. Том действует как отдельный раздел диска, который можно форматировать и использовать для хранения данных. Он может быть полностью выделен для одной ФС или разделен на несколько логических единиц

### **Процессы, службы, запланированные задачи** 

##### **Процессы** 

***Процесс*** - это экземпляр программы, который выполняется на компьютере. Каждый процесс имеет собственное пространство памяти и ресурсы и выполняет определенные задачи, заданные программой 

**Примеры процессов:** 
- ***explorer.exe*** - основной процесс проводника Windows, который обеспечивает работу рабочего стола, панели задач и файлового проводника 
- ***chrome.exe*** - процесс веб-браузера Google Chrome 
- ***svchost.exe*** - процесс, который используется для запуска системных служб Windows, которые разделяют один процесс 

##### **Службы** 

***Служба*** - это фоновый процесс, который выполняет определенные системные или сетевые задачи и обычно запускается автоматически при старте системы 

**Примеры служб:** 
- ***Windows Update*** - управляет установкой обновлений для ОС и других программ 
- ***Print Spooler*** - управляет заданиями на печать, включая очереди и взаимодействие с принтерами 
- ***Windows Defender Antivirus Service*** - обеспечивает защиту системы от вредоносных программ 

### **Запланированные задачи** 

***Запланированные задачи*** - это сценарии, которые настроены для автоматического выполнения по расписанию или при наступлении определенных условий. Запланированные задачи могут использоваться для выполнения различных системных задач или запуска программ 

**Примеры запланированных задач:** 
- Автоматическое обновление системы 
- Создание резервных копий 
- Чистка временных файлов 

### **Реестр** 

***Реестр Windows*** - это иерархическая БД, в которой ОС хранит настройки и параметры для ОС, установленных приложений, драйверов устройств и пользовательских профилей - иначе говоря, конфигурация ОС Windows

### **Пользователи и группы пользователей** 

### **Основные пользователи** 

##### 1. **Машинная учетная запись** 
- ***Описание*** - это специальная УЗ на локально устройстве, предназначенная для идентификации и аутентификации компьютера. Она позволяет устройству взаимодействовать с другими ресурсами и получать доступ к ним на уровне сети
- ***Особенности*** - создаются автоматически во время установки ОС 
##### 2. **Administrator** 
- ***Описание*** - имеет полный контроль над системой и может выполнять любые действия, включая изменение системных настроек, установку программ, управление УЗ и файлами 
- ***Особенности*** - в современных версиях Windows эта УЗ отключена по умолчанию для повышения безопасности. Ее следует включать только при необходимости 
##### 3. **Guest** 
- ***Описание*** - пользователь с минимальными привилегиями для временного доступа 
- ***Особенности*** - не может вносить изменения в систему, использовать системные приложения или устанавливать программы 
##### 4. **Default Account** 
- ***Описание*** - системная УЗ, используемая для внутренних процессов системы 
- ***Описание*** - скрыта и не предназначена для интерактивного входа 
##### 5. **WDAGUtility Account** 
- ***Описание*** - специальная УЗ, используемая для изоляции потенциально опасных приложений 
- ***Особенности*** - не предназначена для ручного использования и доступа только для системных процессов 
##### 6. **System** 
- ***Описание*** - УЗ с высшими привилегиями, используемая ОС для выполнения задач, требующих наибольших прав 
- ***Особенности*** - имеет доступ ко всем ресурсам компьютера и используется для выполнения критических системных задач 
##### 7. **LocalService** 
- ***Описание*** - УЗ с ограниченными правами, используемая для запуска служб, не требующих доступа к ети или система 
- ***Особенности*** - эта УЗ имеет минимальные права и предназначена для обеспечения безопасности при выполнении системных служб 
##### 8. **NetworkService** 
- ***Описание*** - УЗ с правами для выполнения сетевых операций 
- ***Особенности*** - имеет более широкие права доступа 

### **Основные группы пользователей** 

##### 1. **Administrator** 
- ***Описание*** - группа с полным контролем над системой 
- ***Права*** - полный доступ ко всем системным функциям 
##### 2. **Users** 
- ***Описание*** - группа для обычных пользователей 
-  ***Права*** - ограниченный доступ к системным функциям 
##### 3. **Guest** 
- ***Описание*** - группа с минимальными правами, для временных пользователей 
-  ***Права*** - доступ только к базовым функциям 
##### 4. **Backup Operators** 
- ***Описание*** - для резервного копирования и восстановления 
-  ***Права*** - может выполнять операции резервного копирования и восстановление файлов 
##### 5. **Power Users** 
- ***Описание*** - между пользователями и администраторами 
-  ***Права*** - может устанавливать программы и драйверы 
##### 6. **Remote Desktop Users** 
- ***Описание*** - группы, члены которых могут подключаться с помощью удаленного рабочего стола 
-  ***Права*** - позволяет подключаться к удаленной системе 
##### 7. **Event Log Readers** 
- ***Описание*** - предназначенная для чтения журналов событий 
-  ***Права*** - могут просматривать и анализировать системные журналы 
##### 8. **Huper-V Administrators** 
- ***Описание*** - для управления функциями виртуализации 
-  ***Права*** - полный доступ к настройки и управлению виртуальными машинами 
##### 9. **Perfomance Log Users и Perfomance Monitor Users** 
- ***Описание*** - которые должны иметь возможность работать с журналами и данными производительности системы 
-  ***Права*** - чтение и анализ данных производительности системы
