***Active Directory*** - это служба каталогов, централизированная система управления сетевыми ресурсами, для управления пользователями, компьютерами и другими объектами в сетевой инфраструктуре. AD предоставляет сервисы аутентификации, авторизации и поиска, упрощая администрирование и повышает безопасность в корпоративных сетях 

***Контроллер домена (DC)*** - это сервер, на котором установлена роль (служба) AD и которой отвечает за аутентификацию и авторизацию пользователей, управление доступом к ресурсам и хранение данных об объектах в домене. Наличие нескольких контролеров домена в инфраструктуре позволяет обеспечивать целостность и безопасность сети, так как они хранят и реплицируют базу данных AD между собой 

***Домен в AD*** - это логическая группа объектов, таких как пользователи, компьютеры и устройства, объединенных в единое административное пространство. Домен используется для упрощения управления сетевыми ресурсами, позволяя администраторам централизованно управлять политиками безопасности, УЗ и доступом к ресурсам в пределах домена

### **Что такое объекты в AD и какие они бывают** 

***Объекты в AD*** - это сущности, которыми управляет AD. Они представляют собой пользователей, компьютеры, группы, организационные единицы, групповые политики безопасности и другие элементы. Объекты имеют уникальные атрибуты и идентификаторы, которые определяют их свойства и функции в сети 

**Основные типы объектов в AD:** 
- Пользователи 
- Компьютеры 
- Группы 
- Организационные единицы (OU)
- Групповые политики безопасности (GPO)

***Атрибут объекта в AD*** - это характеристики или свойства, которое описывает объект в каталоге AD. Каждый объект в AD, будь то пользователь, группа, компьютер или другой ресурс, имеет набор атрибутов, которые хранят информацию об этом объекте

### **LDAP-Запросы** 

***LDAP*** - это сетевой протокол для доступа и управления информацией и управления информацией в каталогах, таких как AD. LDA-запросы позволяют искать, добавлять, извлекать, изменять и удалять данные в каталоге 

##### **Основные понятия LDAP-запросов** 
1. DN - уникальный идентификатор объекта в LDAP-каталоге, который описывает его местоположение в иерархии
2. Фильтры - условия, которые используются для поиска объектов в каталоге 
3. Атрибуты - свойства объектов в каталоге 
4. Запросы - запросы могут быть SEARCH, ADD, MODIFY, DELETE и другие 

### **Основные параметры командлетов PowerShell для LDAP-запросов** 

##### 1. **Identity** 
- Указывает уникальный идентификатор объекта в AD 
- Применяется для получения информации об одном конкретном объекте 
- Возвращает информацию о пользователе 

```
Get-ADUser -Identity "jdoe"
```
##### 2. **Filter** 
- Задает фильтр для поиска объектов 
- Применяется для выполнения поиска с определенными условиями 
- Возвращает всех пользователей 

```
Get-ADUser -Filter {Title -eq "Manager"}
```
##### 3. **Properties** 
- Определяет список дополнительных атрибутов, которые должны быть возвращены вместе с результатами запроса 
- Позволяет получить не только стандартные, но и дополнительные свойства объекта 
- Возвращает информацию о пользователе, включая его имя и адрес электронной почты 

```
Get-ADUser -Identity "jdoe" -Properties DisplayName, EmailAddress
```
##### 4. **SearchBase** 

- Указывает базовый DN, от которого начинается поиск в иерархии каталога 
- Позволяет ограничить область поиска до определенного контейнера или организационной единицы (OU)
- Возвращает командлет всех пользователей, находящихся в OU Sales 

```
Get-ADUser -SearchBase "OU=Sales,DC=example,DC=com" -Filter *
```
##### 5. **Server** 
- Указывает конкретный контроллер домена с которым PowerShell будет взаимодействовать
- Для выполнения команд и запросов к конкретному серверу
- Получает информацию о пользователе 

```
Get-ADUser -Identity "jdoe" -Server "dc1.example.com"
```
