***PowerShell*** - это современная командная оболочка и скриптовой язык, который объединяет возможности традиционной командной строки со встроенными средствами автоматизации и управления. PowerShell необходим специалистам ИБ, так как предоставляет гораздо более мощные и гибкие инструменты для автоматизации задач, анализ системы и управления конфигураций по сравнению с CMD. Благодаря работе с объектами вместо текстовых строк и возможностям удаленного управления PowerShell позволяет эффективно мониторить и защищать сложные ИТ-инфраструктуры 

***Командлеты (cmdlets)*** - это небольшие специализированные команды, разработанные для выполнения конкретных задач в командной оболочке PowerShell. Все командлеты следуют единому синтаксису и правилам именования: Глагол-Существительное 

***Конвейер (pipeline)*** - это механизм, который позволяет передавать выходные данные одного командлета в качестве входных данных для другого командлета. Это позволяет объединять несколько командлетов в одну последовательность действий, где результаты работы одного этапа автоматически используется на следующем этапе. Конвейер делает автоматизацию задач более простой и эффективной, позволяя обрабатывать и фильтровать данные без необходимости промежуточного хранения результатов 

### **Командлеты PowerShell** 

- `Get-Alias` - показывает список псевдонимов командлетов PowerShell и их соответствия оригинальным командлетам 
- `Get-Command` - получает список всех доступных командлетов, функций, скриптов и алиасов 
- `Get-Help <cmdlet>` - предоставляет справочную информацию по командлетам, их параметрам и использованию 
- `Get-Childitem <path>` - предоставляет список файлов и папок в указанном каталоге

### **Интегрированная среда скриптов PowerShell и сценарии** 

***Интегрированная среда скриптов PowerShell (ISE)*** - предоставляет собой графическую оболочку для разработки, редактирования и выполнения сценариев PowerShell. Она предоставляет удобный интерфейс для написания, тестирования и откладки команд и сценариев PowerShell 

***Сценарии PowerShell (скрипты)*** - это файлы, содержащие последовательности команд и командлетов PowerShell, которые выполняются последовательно для автоматизации задач. Они позволяют объединять несколько команд в один файл и выполнять их как единое целое (скрипт, программа)

### **Основные особенности сценариев** 

##### 1. **Расширение файла** 
- Сценарии PowerShell имеют расширение файла `.ps1`
##### 2. **Гибкость и модульность**
- Сценарии можно разделять на модули, что упрощает их поддержку и повторное использование 
##### 3. **Обработка ошибок, откладка, комментарии** 
- Поддерживает откладку сценариев, что позволяет легко находить и исправлять ошибки в коде 

### **Примеры сценариев PowerShell**

```
# Создание папки
New-Item -Path "C:\temp\MyFolder" -ItemType Directory

# Создание файла в созданной папке
New-Item -Path "C:\temp\MyFolder\myfile.txt" -ItemType File

# Запись текста в файл
"Hello, PowerShell!" | Out-File "C:\temp\MyFolder\myfile.txt"
```

```
# Получение списка пользователей
Get-LocalUser | Select-Object Name, Enabled | Out-File "C:\temp\UserList.txt"
```

```
# Получение информации обо всех службах
Get-Service | Select-Object Name, Status | Format-Table -AutoSize
```

### **Для чего нужны сценарии в работе специалиста ИБ и аналитика SOC** 
- Автоматизация задач 
- Аудит и мониторинг 
- Сбор и обработка данных 
- Ответ на инциденты
