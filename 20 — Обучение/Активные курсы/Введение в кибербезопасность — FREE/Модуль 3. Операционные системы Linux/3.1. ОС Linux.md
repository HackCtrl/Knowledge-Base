### **Дистрибутивы Linux** 

***Дистрибутив Linux*** - это ОС, состоящая из ядра Linux и набора ПО, подобранного для выполнения определенных задач. Основное отличие между различными дистрибутивами заключается в их целевой аудитории, доступных пакетных программ, методах установки и управления системой

### **Популярные дистрибутивы**

- Ubuntu (APT)
- Debian (APT)
- Fedora (DNF)
- CentOS/RHEL (YUM/DNF)
- Arch Linux (Pacman)
- OpenSUSE (Zypper)
- Kali Linux (APT)

### **Отечественный Linux**

- Alt Linux 
- Astra Linux 

### **Файловая система** 

***Файловая система Linux*** - это структура, которая определяет способ хранения, организации и доступа к данным на диске. В отличие от Windows, где каждый диск представлен отдельной буквой, ФС Linux представляет собой единую иерархическую структуру, где все устройства монтируются в одном дереве каталогов 

##### **Особенности ФС Linux** 
- Иерархическая структура 
- Разделение файловой системы 
- Унифицированный доступ к файлам и устройствам

##### **Иерархия директорий в Linux** 

- `/` - корневой каталог
- `/bin` - содержит основные команды и утилиты, доступные для использования всеми пользователями 
- `/etc` - хранит конфигурационные файлы системы 
- `/home` - домашние каталоги пользователей 
- `/var` - данные, которые часто меняются, такие как логи и временные файлы 
- `/usr` - содержит пользовательские программы и библиотеки 
- `/tmp` - временные файлы, которые удаляются при перезагрузке системы 

```
/
├── bin/
├── boot/
├── dev/
├── etc/
├── home/
├── lib/
├── media/
├── mnt/
├── opt/
├── proc/
├── root/
├── sbin/
├── tmp/
├── usr/
└── var/
```

### **Процессы, службы, запланированные задачи** 

##### **Процесс** 

***Процесс*** - это выполнение программы или команды в Linux. Каждый процесс имеет уникальный идентификатор (IP, PID) и может иметь родительский процесс (PPID), который его запустил
- Фоновые процессы 
- Пользовательские процессы 

##### **Команды для работы с процессами**
- `ps` - показывает список запущенных процессов 
- `ps aux` - отображает расширенный список всех процессов 
- `kill` - завершение процессов по его PID
##### **Службы** 

- `systemctl` - основная утилита для управления службами в системах с sestemd 
- `service` - используется для управления службами на системах с SysVinit 

```
systemctl status sshd   # Проверка состояния службы sshd
systemctl start nginx   # Запуск службы nginx
systemctl stop nginx    # Остановка службы nginx
```

***sshd*** - это служба, которая отвечает за работу SSH на сервере. Она позволяет удаленным пользователям безопасно подключаться к серверу через зашифрованное соединение, предоставляя доступ к командной строке или другим сервисам 
##### **Запланированные задачи**

- `cron` - утилита для управления запланированными задачами 

##### **Основные команды для управления запланированными задачами** 
- `crontab -l` - просмотреть текущие запланированные задачи 
- `crontab -e` - редактировать список запланированных задач
- `crontab -r` - удалить все запланированные задачи 

### **Пакетные менеджеры** 

***Пакетные менеджеры*** - это инструменты, которые управляют установкой, обновлением, конфигурацией и удалением ПО в Linux. Они являются неотъемлемой частью ОС Linux, обеспечивая удобство и безопасность в управлении пакетами, которые могут включать программы, библиотеки и другие компоненты системы 

##### **Основные пакетные менеджеры** 

##### 1. **APT** 
- Debian, Ubuntu и их производных 

```
sudo apt update - обновление списка пакетов 
sudo apt upgrade - обновление установленных пакетов 
sudo apt install <package> - установка пакета 
sudo apt remove <package> - удаление пакета
```

- Работает с `.deb` пакетами 
##### 2. **YUM/DNF**
- CentOS, RHEL, Fedora

```
sudo yum update - обновление системы
sudo yum install <package> - установка пакета
sudo yum remove <packege> - удаление пакета 
```

```
sudo dnf install <package>
sudo dnf update
```
##### 3. **Pacman**
- Arch Linux и его производных 

```
sudo pacman -Syu - обновление пакетов 
sudo pacman -S <package> - установка пакета 
sudo pacman -R <package> - удаление пакета 
```

### **Пользователи и группы пользователей** 

***Пользователи и группы пользователей*** - являются основными элементами управления доступом в Linux. В этой системе права доступа и контроль над файлами, процессами и ресурсами основываются на учетных записях пользователей и группах 

##### **Пользователи** 
- `Root (суперпользователь)` - имеет полный доступ ко всем файлам, процессам и настройкам системы 
- `Обычные пользователи` - имеют ограниченные права доступа, которые зависят от настроек администратора 
##### **Группы** 
##### 1. **Primary Group (основная группа)**
- Это группа, которая по умолчанию присваивается всем файлам и директориям, созданным пользователям 
##### 2. **Secondary Groups (вторичные группы)**
- Пользователь может быть членом нескольких вторичных групп. Эти группы предоставляют дополнительные права доступа к файлам и ресурсам, принадлежащим этим группам 
##### 3. **Системные и стандартные группы** 
- Группа, связанная с суперпользователем. Обычно используется для управления доступом к системным файлам и каталогам 
##### 4. **wheel**
- В некоторых дистрибутивах используется для управления правами пользователей на выполнение команд через sudo 
##### 5. **adm**
- Группа, которой разрешено просматривать системные журналы и файлы логов 
##### 6. **sudo** 
- Члены этой группы могут выполнять команды с повышенными привилегиями 
##### 7. **users** 
- Группа по умолчанию для обычных пользователей 

### **Управление пользователями и группами** 

##### **Создание пользователя с указанием группы** 

```
useradd -g groupname username
```
##### **Добавление пользователя в группу** 

```
usermod -aG groupname username
```
##### **Просмотр групп пользователя** 

```
groups username
```
##### **Создание новой группы** 

```
groupadd groupname
```
##### **Удаление пользователя из группы**

```
gpasswd -d username groupname
```

### **Примеры использования групп** 

- Разграничение доступа 
- Совместная работа 
- Контроль доступа к конфиденциальной информации 

### **Управление учетными записями: passwd и shadow** 

- `/etc/passwd` - содержит основную информацию о пользователях, включая имя пользователя, UID, GID и путь к домашнему каталогу 

```
username:x:1001:1001:User Name,,,:/home/username:/bin/bas
```

- `/etc/shadow` - содержит хешированные пароли и информацию о политике паролей. Этот фай защищен более строго и доступен только суперпользователям 

```
username:$6$randomsalt$encryptedpassword:18610:0:99999:7:::
```

- `/etc/group` - содержит информацию о группах и их членах 

```
developers:x:1002:john,alice
```

### **Права на файл/директорию**

- Владелец (Owner)
- Группа (Group)
- Остальные (Others)

### **Типы прав** 

- Чтение (r)
- Запись (w)
- Выполнение (x)

```
rwxr-xr--
```

- **rwx** — права владельца (r = 4, w = 2, x = 1; суммарное значение = 7)
- **rwx** — права владельца (r = 4, w = 2, x = 1; суммарное значение = 7)
- **r--** — права остальных (r = 4; суммарное значение = 4)

### **Пример команд** 

##### **Просмотр прав на файл** 

```
ls -l filenam
```
##### **Изменение владельца файла** 

```
chown new_owner filename
```
##### **Изменение группы** 

```
chgrp new_group filename
```
##### **Изменение прав** 

```
chmod 755 filename
```

### **su и sudo** 

- `su` - команда позволяет переключиться на другого пользователя 

```
su - username
```

- `sudo` - позволяет выполнять отдельные команды от имени суперпользователя или другого пользователя, без необходимости полностью переключаться на него

```
sudo command
```

```
sudo apt-get update
```
