## Компоненты SQL Server

Для учебного стенда установлены только «Службы ядра СУБД».

Не устанавливались компоненты машинного обучения, PolyBase,
репликация и службы аналитики, так как они не требуются для баз
ЦУС и УКЦ и создают дополнительную нагрузку.

Тип экземпляра: экземпляр по умолчанию.
Имя экземпляра: MSSQLSERVER.

## Результат установки

- Продукт: Microsoft SQL Server 2019 Developer
- Экземпляр: MSSQLSERVER
- Установленный компонент: службы ядра СУБД
- Режим аутентификации: смешанный — Windows и SQL Server
- Администратор Windows добавлен в SQL Server
- Максимальная память SQL Server: 1536 МБ
- Результат установки: успешно
