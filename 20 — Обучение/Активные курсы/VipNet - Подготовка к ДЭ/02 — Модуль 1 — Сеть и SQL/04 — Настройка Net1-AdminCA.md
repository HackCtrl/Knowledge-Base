
## Результат настройки Net1-AdminCA

- Имя сервера: Net1-AdminCA
- Экзаменационный интерфейс: LAN1-ADMIN
- IP-адрес: 192.168.110.10/28
- Маска: 255.255.255.240
- Интерфейс подключён к мосту vmbr1
- Шлюз временно не назначен
- TEMP-INTERNET используется только для установки программного обеспечения

## Проверка

- Состояние адреса: Preferred
- Доступ в интернет: есть
- Разрешение DNS-имён: работает
- Имя компьютера проверено командой hostname

## Почему шлюз не указан

До создания Net1-FW сервер использует временный выход в интернет через
TEMP-INTERNET. После развёртывания межсетевого экрана рабочим шлюзом
LAN1-ADMIN станет 192.168.110.1.
