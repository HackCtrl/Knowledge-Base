# Ценность активного обучения для работодателя

> [!info] Статус страницы
> Это публично-безопасное описание учебного профиля. Оно не заявляет профессиональный опыт, сертификаты или полное владение технологиями.

## В каких направлениях развивается специалист

- основы информационной безопасности и моделирование действий нарушителя;
- компьютерные сети и протоколы;
- Linux и Windows с точки зрения защиты и аудита;
- сбор, поиск и анализ событий безопасности;
- SIEM, WAF, IDS/IPS и защита периметра;
- Python для небольших задач обработки данных;
- SQL для выборки, фильтрации и объединения данных;
- основы платформы 1С и встроенного языка.

## Какой фундамент формируют курсы

| Фундамент | Что изучается |
|---|---|
| Сетевой | OSI, Ethernet, TCP/IP, IPv4, CIDR, маршрутизация и сетевые службы |
| Системный | Linux, права доступа, hardening, auditd, Windows, Sysmon и GPO |
| Защитный | Риски, этапы атак, сегментация, защита конечной точки и периметра |
| Аналитический | Журналы, временные линии, KQL, IOC, YARA и Threat Hunting |
| Программный | Python, SQL и основы BSL |

## Какие технологии изучаются

Linux, Windows Event Log, OpenSCAP, auditd, iptables, Autoruns, Sysmon, Elastic Stack, Kibana, Fleet, WAF, ModSecurity, Snort, Suricata, YARA, PostgreSQL, Python, JSON, XML и 1С:Предприятие.

Формулировка «изучаются» означает наличие материалов и практики разной глубины, а не производственное владение всем перечнем.

## Какие задачи уже отрабатываются

- анализ структуры атаки и защитных мер;
- построение схемы источников событий;
- поиск событий веб-приложения по временному окну;
- анализ признаков закрепления и повышения привилегий;
- работа с Sysmon, auditd и Autoruns в учебной среде;
- написание Python-кода для разбора строк, JSON и XML;
- написание SQL-запросов с фильтрами, датами и `JOIN`;
- решение базовых задач на BSL;
- расчёт адресации и объяснение прохождения сетевого трафика.

## Какие практические материалы существуют

- структурированные конспекты активных курсов;
- учебные лабораторные по SIEM и анализу журналов;
- Python-скрипты и SQL-запросы;
- разборы OWASP, Autoruns, Sysmon и auditd;
- решения по разведке и сетевой сегментации;
- собственные страницы повторения и самопроверки.

См. [[06 — Реестр учебных доказательств]].

## Какие профессиональные роли становятся ближе

| Роль | Почему становится ближе | Честное ограничение |
|---|---|---|
| Начинающий SOC/Monitoring Analyst | Есть SIEM, веб-логи, Sysmon, auditd, WAF/IDS и KQL-практика | Нужны дополнительные самостоятельные расследования и detection rules |
| Начинающий специалист по ИБ | Изучаются риски, атаки, hardening, сегментация и реагирование | Нет заявления о производственном опыте |
| Системный специалист с уклоном в безопасность | Есть Linux, Windows, сети, аудит и конфигурационные основы | Нужны оформленные воспроизводимые лаборатории |
| Начинающий специалист по автоматизации ИБ | Есть Python-парсинг и SQL-аналитика | Пока нет цельной утилиты и общего security-проекта |
| Начинающий разработчик 1С | Есть основы платформы и BSL | Нет законченной конфигурации и прикладного проекта |

## Чем обучение отличается от просмотра лекций

- ведутся собственные конспекты и связанные страницы содержания;
- выполняются задачи с кодом и запросами;
- фиксируются лабораторные действия и результаты;
- ошибки исходных решений проверяются и исправляются;
- создаются вопросы для самопроверки;
- материалы связываются между дисциплинами;
- выделяются артефакты, которые можно показать после проверки конфиденциальности.

## Что безопасно демонстрировать

> [!success]
> - [[Подробное повторение SQL]];
> - Python-задачи на синтетических данных;
> - [[Повторение глав 1–6]];
> - обзорные страницы по кибербезопасности после проверки ссылок;
> - структуру профессионального дашборда;
> - обезличенную практику анализа веб-логов.

## Что требует предварительной очистки

> [!warning]
> Лабораторные конфигурации SIEM, внутренние адреса, учётные данные, персональные пути, скриншоты и материалы разведки необходимо проверять отдельно. Они не включены в публичные утверждения этой страницы.
