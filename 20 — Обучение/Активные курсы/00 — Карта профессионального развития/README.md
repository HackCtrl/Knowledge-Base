# Карта профессионального развития по активным курсам

Раздел связывает активные курсы с формируемыми компетенциями, практическими результатами и учебными доказательствами. Он отвечает не на вопрос «какой урок проходить следующим», а на вопрос «какой профессиональный профиль складывается из текущего обучения».

## Состав раздела

1. [[00 — Дашборд активного обучения]] — общая точка входа.
2. [[01 — Карта компетенций]] — реальные компетенции и уровень их подтверждения.
3. [[02 — Матрица Курсы × Компетенции]] — вклад каждого курса в общий профиль.
4. [[03 — Дорожная карта развития специалиста]] — уровни формирования специалиста без дат и расписания.
5. [[04 — Синергия активных курсов]] — связи между дисциплинами.
6. [[05 — Ценность для работодателя]] — публично-безопасное описание учебного профиля.
7. [[06 — Реестр учебных доказательств]] — артефакты, подтверждающие обучение.
8. [[07 — Зоны дальнейшего усиления]] — пробелы внутри уже активных курсов.

- [[Python для кибербезопасности — содержание]] — архивный справочный курс;
- UserGate, OPNsense и MikroTik CHR — отложены;
- инструменты не образуют самостоятельных направлений.

## Правила обновления

- включать курс только при подтверждённом активном статусе;
- выводить компетенцию только при наличии содержательных материалов;
- разделять ознакомление, изучение, практику и демонстрационный артефакт;
- связывать вывод с исходной заметкой или практикой;
- не переносить секреты, реальные адреса и персональные данные;
- не учитывать работу, колледж и проекты на этом этапе;
- пересматривать карту после появления новых практических результатов.

## Связь с исходными курсами

Исходные конспекты остаются внутри своих курсов. Этот раздел не заменяет их и не копирует полностью: он связывает назначения курсов, компетенции, доказательства и межкурсовые зависимости.

## Граница текущего этапа

[[00 — Дашборд активного обучения]] — внутренний аналитический слой только по активным курсам. Будущий общий профессиональный профиль сможет дополнительно включить работу, проекты, техническую поддержку и другое обучение, но эти источники здесь намеренно не используются.
