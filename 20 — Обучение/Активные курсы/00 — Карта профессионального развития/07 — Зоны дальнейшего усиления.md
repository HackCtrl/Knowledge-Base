# Зоны дальнейшего усиления

Пробелы определены только относительно шести активных курсов. Новые курсы и общий карьерный план здесь не предлагаются.

## Недостаточно связанные знания

| Связь | Текущее состояние | Чего не хватает внутри активного обучения |
|---|---|---|
| Python ↔ SIEM | Есть парсинг текста, JSON и XML | Единой утилиты обработки обезличенных событий и отчёта |
| SQL ↔ расследование | Есть фильтры, даты и JOIN | Security-датасета и запросов под гипотезу расследования |
| Сети ↔ IDS/IPS | Есть протоколы и обзор сетевых средств | Разбора одного трафикового сценария от пакета до alert |
| Linux ↔ SIEM | Есть auditd и Elastic Stack | Полного маршрута события с контролем доставки |
| 1С ↔ SQL | Есть прикладная логика и реляционные запросы | Практического артефакта, связывающего модель данных и приложение |
| 1С ↔ ИБ | Есть только основы платформы и BSL | Материалов по ролям, аудиту и безопасной конфигурации 1С |

## Темы без достаточной практики

- NTA/NBA, BAS, UEBA и SOAR представлены обзорно;
- Threat Hunting не завершён отдельным самостоятельным отчётом;
- облачный аудит, IAM, GPO и безопасность почты в основном законспектированы;
- DLP изучена на уровне назначения;
- сетевые главы содержат вопросы, но нет оформленного Packet Tracer-стенда;
- IBN изучена концептуально;
- защита БД не подтверждена отдельной лабораторной.

## Практика без оформленного результата

- демонстрация антивирусных инструментов просмотрена, но не повторена как самостоятельная работа;
- часть лабораторий содержит ход действий, но не имеет структуры «цель → проверка → вывод»;
- [[Решение — сетевая сегментация]] не завершено;
- Sysmon ДЗ зафиксировано частично;
- практика SIEM содержит установку, но не отдельное правило обнаружения с тестом;
- сетевые задания не собраны в отдельный отчёт с ответами.

## Материалы без собственного вывода

- часть конспектов представляет определения и списки инструментов;
- заметки по GPO, облакам, БД, WAF/IDS и honeypot нуждаются в кратком выводе «когда применять и как проверить»;
- отдельные Python-задачи объясняют решение, но не сравнивают альтернативы и обработку ошибок;
- часть задач 1С содержит исходные опечатки, которые исправлены только в странице повторения.

## Навыки без демонстрационного артефакта

| Навык | Какого артефакта не хватает |
|---|---|
| Detection engineering | Карточка правила, тестовые события и результат проверки |
| Threat Hunting | Гипотеза, запросы, охват, находки и пробелы телеметрии |
| Реагирование | Настольный сценарий с ролями, таймлайном и post-incident review |
| Сетевой анализ | PCAP или Packet Tracer-схема с объяснением трафика |
| Python-автоматизация | Цельная утилита с аргументами, ошибками и тестами |
| SQL для ИБ | Набор запросов по обезличенным событиям |
| 1С | Небольшая учебная конфигурация с воспроизводимым сценарием |

## Направления, развиваемые преимущественно одним курсом

- фундаментальные сети — сетевой курс;
- Python — курс Python для кибербезопасности;
- SQL — курс SQL;
- BSL и платформа 1С — курс 1С;
- облачная, почтовая и deception-инфраструктура — курс по противодействию кибератакам.

Это не недостаток само по себе, но устойчивость компетенции пока меньше, чем у тем, повторяющихся в нескольких курсах.

## Неоднозначные или недостаточно подтверждённые компетенции

- установка инструмента не доказывает умение сопровождать его в production;
- выполнение задания по инструкции не равно самостоятельному расследованию;
- наличие примера YARA не доказывает разработку качественных правил;
- обзор WAF/IDS не доказывает настройку и тюнинг;
- наличие конспекта hardening не доказывает безопасное применение на рабочей системе;
- созданные страницы повторения подтверждают систематизацию знаний, но не заменяют практическую проверку.

## Приоритет усиления внутри текущих материалов

1. Доводить начатые практики до проверяемого результата.
2. Добавлять собственный вывод и критерии успешности.
3. Обезличивать и оформлять лучшие работы как демонстрационные артефакты.
4. Связывать Python и SQL с уже существующими учебными логами.
5. Проверять ошибочные и устаревающие настройки перед повторным использованием.
