# Карта компетенций

Уровни описывают подтверждение внутри пяти постоянных курсов, временной подготовки ViPNet и сохранённых учебных артефактов, а не профессиональный стаж. Архивный материал может оставаться источником доказательства, но не считается текущей нагрузкой.

| Уровень | Критерий |
|---|---|
| Ознакомление | Тема появилась в материалах, но не раскрыта отдельной практикой |
| Изучение | Есть содержательные конспекты и понимание основ |
| Практика | Есть упражнения или лабораторные действия |
| Подтверждено материалами | Есть понятный артефакт, который можно показать |
| Требует проверки | Данных недостаточно для вывода |
