# Реестр архивирования направлений

## Перестройка 2026-11-18

Главный фокус изменён на кибербезопасность. Активны новый курс «Введение в кибербезопасность», компьютерные сети и ViPNet со стендом.

| Направление | Причина архивирования | Условие возврата |
|---|---|---|
| [[SQL — содержание]] | Приостановлено, чтобы не дробить фокус | Конкретная задача по данным, ИБ или 1С |
| [[1С для начинающих — содержание]] | Приостановлено; рабочее сопровождение 1С остаётся отдельным опытом | Явная цель по BSL или прикладной задаче |
| [[Специалист по кибербезопасности — содержание]] | Материалы и практики сохранены; новый курс выбран основным маршрутом | Точечное возвращение к лабораторной |
| [[Специалист по противодействию кибератакам — содержание]] | Углублённый справочный материал по SIEM и реагированию | После базы нового курса или под задачу детекции |
| [[00 — Дашборд двухдневного повторения]] | Относится к приостановленным направлениям | Отдельное решение о возврате к курсу |
| [[00 — Стратегия обучения]], [[00 — Дашборд активного обучения]] | История предыдущего плана | Только для просмотра истории и артефактов |
