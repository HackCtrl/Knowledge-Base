## Правила обновления

1. Менять статус компетенции только после появления конспекта, выполненного задания или проверяемого результата.
2. Не считать обычный конспект подтверждением практического навыка.
3. Не переносить сюда секреты, реальные адреса инфраструктуры, персональные и служебные данные.
4. Новые курсы не добавлять в план автоматически: сначала завершать активные, повторять пройденное и оформлять практику.
5. Китайский язык ведётся отдельно и в этот профиль не включается.

## Граница раздела

Этот раздел описывает учебный профессиональный профиль. Он не объединяет рабочий опыт, DTEK Core и CyberWhale: проектные страницы пока имеют статус `planned` и не содержат подтверждающих материалов. Будущий общий профиль сможет использовать этот раздел как один из проверенных слоёв.
