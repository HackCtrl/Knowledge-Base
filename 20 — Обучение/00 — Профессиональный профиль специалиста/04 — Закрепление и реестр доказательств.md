# Закрепление и реестр доказательств

## Принцип закрепления

Каждое задание занимает примерно 15–60 минут, использует уже изученную тему и заканчивается сохранённым результатом. Новые большие курсы для выполнения не нужны.

## Реестр существующих доказательств

Категории видимости:

- `Публичное` — материал можно использовать как учебный пример после обычной проверки отображения;
- `Можно показывать после проверки` — нужно проверить скриншоты, имена, пути, метаданные и формулировки;
- `Только для личного использования` — материал полезен для обучения, но не предназначен для публикации;
- `Содержит потенциально чувствительные данные` — требуется отдельная очистка, значения в этом реестре не копируются.
