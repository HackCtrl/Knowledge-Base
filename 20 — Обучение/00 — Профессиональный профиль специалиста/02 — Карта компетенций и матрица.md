# Карта компетенций и матрица

## Правила оценки

| Статус | Как интерпретируется |
|---|---|
| Ознакомился | Тема встречалась, но данных недостаточно для более сильного вывода |
| Изучаю | Есть актуальные конспекты и развитие темы |
| Понимаю теоретически | Есть содержательная теория без отдельной практики |
| Применял на учебном примере | Выполнено упражнение или лабораторная в учебной среде |
| Применял на практике | Есть подтверждённое применение вне учебного задания |
| Подтверждено материалами | Есть понятный проверяемый артефакт |
| Нужно повторить | Материал архивный, фрагментарный или давно не закреплялся |
| Требует проверки | Данных недостаточно или артефакт ещё не просмотрен |

> [!note] Граница оценки
> Статус «Применял на практике» не назначен: рабочие материалы не анализировались и не переносились в учебный профиль. Выполненные лабораторные отмечены как учебные примеры.

## Вывод по матрице

- сети, ОС, доступ, журналы и документирование — общий фундамент всех трёх направлений;
- SQL напрямую нужен для данных 1С и администрирования БД, а в ИБ помогает анализировать события;
- Python и скриптинг связывают администрирование с защитной аналитикой;
- прикладная логика 1С пока слабо связана с ИБ практическими артефактами;
- ViPNet полезен прежде всего на пересечении сетей, криптографической защиты и администрирования, а для 1С играет инфраструктурную роль.
