***ausearch*** - это утилита командной строки для поиска и анализа записей в журналах аудита, которые создает система аудита Linux (в частности демон auditd). ***audisp (точнее, audispd)*** - это мультиплексор аудита в Linux. Он работает в связке с доменом auditd, который отвечает за сбор и обработку событий аудита в системе. То есть он принимает сообщения о том, что происходит в системе и распределяет их между разными программами для дальнейшей обработки

добавим правило для приема логов: 
```
sudo bash -c 'echo "tcp_listen_port = 60" >> /etc/audit/auditd.conf'
sudo bash -c 'echo "tcp_max_per_addr = 5" >> /etc/audit/auditd.conf'
```

откроем порт ufw: 
- `sudo ufw allow 60/tcp`

Перезапустить проверки: 
```
sudo systemctl restart auditd
sudo systemctl status auditd
sudo ss -tlnp | grep 60
```
