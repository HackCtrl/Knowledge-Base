### ***Практика ОС*** 

По умолчанию включим демон auditctl:
- `auditctl -l` 

*Все правила по умолчанию выключены, сейчас по не многу будем настраивать их* 

Конфиг находится `/etc/audit/auditd.conf` где мы сейчас немого настроим под себя: 
- `flush` - важный параметр, логи могут записываться инкрементально или потоком 
	- **Инкрементально** - значит логи будут записываться с какой то периодичностью, будет набираться какое то количество событий, например `freq = 50`, то есть берется 50 событий, будут отправлены и будут записаны 
- `max_log_file` - максимальное количество логов, если их набирается больше, чем мы указали, то что то произойдёт 

***Напишем первое правило:*** 
- `auditctl -w /etc/passwd -p wa -k passwd_write` - любое изменение `/etc/passwd` запишется в `/var/log/audit/audit.log` с меткой `passwd_write`
![[Pasted image 20260822093808.png]]

- `auditctl -w /etc/ssh/sshd_config -p warx -k sshd_config` - любое обращение к `sshd_config` (чтение, изменение, запуск) попадет в лог с меткой `sshd_config`

`tail -f /var/log/audit/audit.log` - режим реального времени, показывает новые строки в логе по мере их появления 

![[Pasted image 20260822094347.png]]

`cat /etc/ssh/sshd_config` - прочитать наш конфиг 

![[Pasted image 20260822094759.png]]

- `auditctl -a always,exit -F arch=x86_64 -S open -F auid=0` - каждый раз, когда root открывает любой файл через `open()`, это попадает в лог 
- `auditctl -a exit,always -F arch=x86_64 -S mkdir` - отслеживает любой процесс (любой пользователь) создающий папку через `mkdir` - попадает в лог
