В XML-документах информация часто содержится не только в атрибутах тегов, но и непосредственно как **текстовое содержимое** между открывающим (`<tag>`) и закрывающим (`</tag>`) тегами.

Системы мониторинга или оповещения могут передавать информацию о событиях в XML-формате. Например, сообщение об инциденте безопасности может содержаться внутри тега `<message>`.

**Цель**

Написать программу на Python, которая:
1. Получает на вход **одну строку**, содержащую XML-данные об оповещении (через стандартный ввод).
2. Парсит эту XML-строку.
3. Находит тег `<message>` (предполагается, что он находится непосредственно внутри корневого тега).
4. Извлекает из этого тега его **текстовое содержимое**.
5. Выводит на экран **только это текстовое содержимое** (без самого тега).

**Пример ввода 1:**

`<alert><message>Unauthorized access detected</message><severity>High</severity></alert>`

**Пример вывода 1:**

`Unauthorized access detected`

**Пример ввода 2:**

`<event id="e99"><source>firewall</source><message>Port scan from 10.0.0.99</message></event>`

**Пример вывода 2:**

`Port scan from 10.0.0.99`

**Пример ввода 3 (пустой тег):**

`<log><entry id="1"><message></message></entry></log>`

**Пример вывода 3:**

`(пусто, ничего не выводится)`

*Эта задача научит вас извлекать текстовые данные, заключенные внутри XML-тегов.*

### ***Теория***

**Поиск элемента: `element.find(tag_name)`**

```
import xml.etree.ElementTree as ET
import sys

xml_string = sys.stdin.read()
root = ET.fromstring(xml_string)
# Ищем первый тег  внутри корневого элемента
message_element = root.find("message")
```

**Доступ к текстовому содержимому: атрибут `element.text`**

У объекта Element, представляющего тег, есть атрибут `.text`. Он содержит текстовые данные, находящиеся непосредственно внутри этого тега (между открывающим и закрывающим тегами), но **не включает** текст из вложенных тегов)

```
# Предположим, message_element - это результат поиска тега 
if message_element is not None: # Проверяем, что тег найден
    message_text = message_element.text
    # message_text теперь содержит строку "Unauthorized access detected" или "Port scan from 10.0.0.99"
    print(message_text)
else:
    print("Тег  не найден.")
```

**Важные моменты об атрибуте `.text`:**
- Если тег не содержит текста (например, `<message/>` или `<message><child/></message>`), атрибут `.text` будет равен `None`.
- Если тег пустой (например, `<message></message>`), атрибут `.text` будет равен пустой строке `""`.
- Атрибут `.text` содержит текст "как есть", включая возможные пробелы или переводы строк по краям, если они были в XML. Их можно удалить с помощью метода `.strip()`, если требуется.
