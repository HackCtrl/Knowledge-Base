**XML** (eXtensible Markup Language) — это язык разметки, похожий на HTML, но используемый для хранения и передачи структурированных данных. Он часто применяется в файлах конфигурации, протоколах обмена данными и форматах отчетов.

XML состоит из тегов (`<tag>...</tag>`), которые могут содержать текст, другие теги или иметь **атрибуты** (пары `**имя="значение"**` внутри открывающего тега).

Представьте, что у вас есть конфигурационный файл в формате XML, описывающий различные сервисы системы. Вам нужно узнать имя конкретного сервиса, которое указано в атрибуте `name` тега `<service>`.

**Цель**

Написать программу на Python, которая:
1. Получает на вход **одну строку**, содержащую данные конфигурации в формате XML (через стандартный ввод).
2. Парсит эту XML-строку.
3. Находит тег `<service>` (предполагается, что он находится непосредственно внутри корневого тега).
4. Извлекает из этого тега значение атрибута `name`.
5. Выводит на экран **только значение этого атрибута**.

**Пример ввода:**

`<config><service name="database" type="mysql"><port>3306</port></service></config>`

**Пример вывода для этого ввода:**

`database`

**Другой пример ввода:**

`<system><version>1.2</version><service name="auth-api" vendor="internal"><host>localhost</host></service></system>`

**Пример вывода для этого ввода:**

`auth-api`

*Эта задача познакомит вас с основами парсинга XML в Python и извлечением данных из атрибутов тегов.*

### ***Теория*** 

Для работы с XML в Python есть несколько библиотек. Одна из стандартных и достаточно простых — `xml.etree.ElementTree`

***Импорт модуля***

Обычно его импортируют под коротким псевдонимом `ET` для удобства:

```
import xml.etree.ElementTree as ET
```

***Парсинг XML-строки: Функция `ET.fromstring(xml_string)`***

Эта функция принимает строку, содержащую XML, и парсит ее, возвращая корневой **элемент** (Element) дерева XML

```
import xml.etree.ElementTree as ET
import sys

xml_string = sys.stdin.read()
# Парсим строку в дерево элементов, root - это корневой элемент (<config> или <system> в примерах)
root = ET.fromstring(xml_string)
```

***Поиск дочерних элементов: метод `element.find(tag_name)`***

У каждого элемента (начиная с корневого) есть методы для поиска вложенных элементов. Метод `.find()` ищет **первый** непосредственный дочерний элемент с указанным именем тега и возвращает его как объект Element

```
# Ищем первый тег  внутри корневого элемента 'root'
service_element = root.find("service")
# service_element теперь - объект Element, представляющий тег 
```

*Если элемент с таким тегом не найден, `.find()` возвращает `None`*

***Получение значения атрибута: метод `element.get(attribute_name)`***

Чтобы получить значение атрибута у найденного элемента, используется метод `.get()`. Он принимает имя атрибута и возвращает его значение (в виде строки)

```
# У найденного элемента  получаем значение атрибута 'name'
if service_element is not None: # Важно проверить, что элемент найден!
    service_name = service_element.get("name")
    # service_name теперь содержит строку "database" или "auth-api"
    print(service_name)
else:
    print("Тег  не найден")
```

Преимущество `.get()` в том, что если атрибут с таким именем отсутствует у элемента, он вернет `None`, а не вызовет ошибку (в отличие от прямого доступа через `element.attrib['name']`, который вызвал бы `KeyError`)

### ***Решение***

```
# 1. Импортируйте ElementTree как ET и модуль sys
import xml.etree.ElementTree as ET
import sys

# 2. Прочитайте всю XML-строку из стандартного ввода
xml_string = sys.stdin.read()

try:
    # 3. Распарсите XML-строку с помощью ET.fromstring()
    root = ET.fromstring(xml_string)

    # 4. Найдите элемент 'service' внутри корневого элемента (root)
    service_elem = root.find("service")

    # 5. Проверьте, что элемент 'service' найден (не None)
    if service_elem is not None:

        # 6. Если найден, получите значение атрибута 'name' с помощью .get()
        name_attr = service_elem.get("name")

        # 7. Проверьте, что атрибут 'name' существует (значение не None)
        if name_attr is not None:

            # 8. Если существует, выведите значение атрибута
            print(name_attr)

except ET.ParseError:
    # Ошибка парсинга XML - ничего не делаем в этой задаче
    pass
```
