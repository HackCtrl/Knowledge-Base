Данные в формате JSON часто имеют иерархическую, или **вложенную**, структуру. Это означает, что значением для какого-то ключа может быть другой JSON-объект (словарь) или JSON-массив (список), которые, в свою очередь, содержат свои ключи и значения.

Представьте, что вы получаете события безопасности в формате JSON. Каждое событие содержит общую информацию, а также вложенный объект с деталями об источнике события, включая его IP-адрес.

**Цель**

Написать программу на Python, которая:
1. Получает на вход **одну строку**, содержащую информацию о событии в формате JSON (через стандартный ввод).
2. Парсит эту JSON-строку.
3. Извлекает из полученной структуры данных IP-адрес источника события. Для этого нужно сначала получить доступ к объекту по ключу `"event"`, затем внутри него — к объекту по ключу `"source"`, и наконец, внутри него — к значению по ключу `"ip"`.
4. Выводит на экран **только этот IP-адрес**.

**Пример ввода:**

`{"event": {"timestamp": "2023-10-27T10:00:00Z", "type": "login_failed", "source": {"ip": "10.1.1.1", "port": 54321}}}`

**Пример вывода для этого ввода:**

`10.1.1.1`

**Другой пример ввода:**

`{"event": {"id": "xyz789", "source": {"hostname": "attacker-pc", "ip": "198.51.100.99"}}, "severity": "high"}`

**Пример вывода для этого ввода:**

`198.51.100.99`

*Эта задача научит вас навигировать по вложенным структурам данных, полученным из JSON.*

### ***Теория*** 

***Парсинг JSON***

Как и раньше, мы используем `import json` и функцию `json.loads()` для преобразования JSON-строки в объект Python. Если корневой элемент JSON — это объект `{...}`, то `json.loads()` вернет словарь Python.

```
import json
import sys

json_string = sys.stdin.read()
data = json.loads(json_string)
# data теперь - словарь Python
```

***Доступ к вложенным значениям***

Если значением в словаре является другой словарь, доступ к значениям во вложенном словаре осуществляется последовательно, с использованием нескольких пар квадратных скобок `[]`

```
data = {
    "event": {
        "timestamp": "2023-10-27T10:00:00Z",
        "type": "login_failed",
        "source": {
            "ip": "10.1.1.1",
            "port": 54321
        }
    },
    "severity": "high"
}
```

***Чтобы получить доступ к IP-адресу:***

Сначала получаем вложенный словарь по ключу `"event"`: `event_data = data["event"]`  
`event_data` будет:

```
{
    "timestamp": "2023-10-27T10:00:00Z",
    "type": "login_failed",
    "source": {
        "ip": "10.1.1.1",
        "port": 54321
    }
}
```

Затем из `event_data` получаем еще более вложенный словарь по ключу `"source"`: `source_data = event_data["source"]`  
`source_data` будет:

```
{
    "ip": "10.1.1.1",
    "port": 54321
}
```

1. Наконец, из `source_data` получаем значение по ключу `"ip"`: `ip_address = source_data["ip"]`  
    `ip_address` будет: `"10.1.1.1"`

**Сокращенная запись.** Эти шаги можно объединить в одну строку:

```
ip_address = data["event"]["source"]["ip"]
print(ip_address) # Выведет: 10.1.1.1
```

### ***Решение*** 

```
# 1. Импортируйте модули json и sys
import json
import sys

# 2. Прочитайте всю строку JSON из стандартного ввода
json_string = sys.stdin.read()

# 3. Распарсите JSON-строку с помощью json.loads()
data = json.loads(json_string)

# 4. Получите доступ к IP-адресу через вложенные ключи:
#    Сначала ключ 'event', потом 'source', потом 'ip'
ip = data["event"]["source"]["ip"]

# 5. Выведите полученный IP-адрес
print(ip)
```
