Системы анализа логов, сообщений или другого текстового контента часто ищут ключевые слова, которые могут указывать на подозрительную активность или требующие внимания события. Например, слова "hack" или "attack" могут сигнализировать о возможной атаке (утрированный пример).

Ваша задача — написать простую программу, которая проверяет наличие таких "подозрительных" слов в заданном тексте, не обращая внимания на регистр букв.

**Цель**

Написать программу на Python, которая:
1. Читает **весь текст** (возможно, многострочный) из стандартного потока ввода (stdin).
2. Проверяет, содержит ли этот текст слово `"hack"` или слово `"attack"`. Проверка должна быть **нечувствительной к регистру** (т.е. "Hack", "HACK", "attack", "ATTACK" тоже должны считаться совпадениями).
3. Выводит на экран слово `True`, если найдено хотя бы одно из этих слов (в любом регистре).
4. Выводит на экран слово `False`, если ни одно из этих слов не найдено.

**Пример ввода 1:**

`User jsmith reported a possible attack on the main server.`
`Log entry: ID12345`
`Timestamp: 2023-10-27`

**Пример вывода 1:**

`True`

**Пример ввода 2:**

`System update completed successfully. All services nominal.`
`Next check scheduled for tomorrow.`

**Пример вывода 2:**

`False`

**Пример ввода 3 (другой регистр):**

`WARNING: Unusual login pattern detected. Possible HACK attempt?`

**Пример вывода 3:**

`True`

*Эта задача научит вас искать подстроки в тексте и работать с регистром символов.*

### ***Теория*** 

***Чтение всего стандартного ввода: `sys.stdin.read()`***

Чтобы прочитать весь текст, поданный на стандартный ввод (включая несколько строк), мы используем `sys.stdin.read()` после импорта модуля `sys`. Этот метод возвращает все содержимое как одну большую строку.

```
import sys
full_text = sys.stdin.read()
```

***Преобразование к нижнему регистру: метод `.lower()`***

```
original_text = "WARNING: Possible HACK!"
lower_text = original_text.lower()
# lower_text теперь содержит "warning: possible hack!"
print(lower_text)
```

***Проверка наличия подстроки: оператор `in`***

Чтобы проверить, содержится ли одна строка (подстрока) внутри другой строки, используется оператор `in`. Он возвращает булево значение (`True` или `False`).

```
подстрока in строка
```

```
text = "user logged in successfully"
keyword = "logged"
if keyword in text:
    print(f"Слово '{keyword}' найдено!") # Это будет напечатано
else:
    print(f"Слово '{keyword}' не найдено.")

result = "error" in text # result будет False
print(result)
```

***Логическое ИЛИ: оператор `or`***

Нам нужно проверить наличие или слова "hack", или слова "attack". Для объединения двух логических условий используется оператор `or`. Результат будет `True`, если хотя бы одно из условий истинно.

```
found = ("hack" in text) or ("attack" in text)
```

Переменная `found` будет `True`, если в тексте есть "hack", или если есть "attack", или если есть оба слова.

### ***Решение***

```
# 1. Импортируйте модуль sys
import sys

# 2. Прочитайте весь текст из стандартного ввода
input_text = sys.stdin.read()

# 3. Преобразуйте текст к нижнему регистру
lower_text = input_text.lower()

# 4. Задайте искомые ключевые слова (в нижнем регистре)
keyword1 = "hack"
keyword2 = "attack"

# 5. Проверьте, содержится ли хотя бы одно из ключевых слов в тексте
#    Используйте оператор 'in' и логический оператор 'or'
result = (keyword1 in lower_text) or (keyword2 in lower_text)

# 6. Выведите результат (True или False)
print(result)
```
