Конфигурации сетевых устройств, таких как брандмауэры (firewalls), часто хранятся или передаются в формате JSON. Такая конфигурация может содержать общие параметры политики и список конкретных правил (разрешить/запретить определенные порты или протоколы).

Ваша задача — извлечь из JSON-конфигурации именно список правил.

**Цель** 

Написать программу на Python, которая:
1. Получает на вход **одну строку**, содержащую конфигурацию брандмауэра в формате JSON (через стандартный ввод).
2. Парсит эту JSON-строку.
3. Извлекает из полученной структуры данных **список**, соответствующий ключу `"rules"`.
4. Выводит на экран **только этот список**, используя стандартное представление списков Python (как это делает функция `print()`).

**Пример ввода:**

`{"policy_name": "default", "rules": [{"action": "allow", "port": 80, "protocol": "tcp"}, {"action": "deny", "port": 23, "protocol": "tcp"}]}`

**Пример вывода для этого ввода:**

`[{'action': 'allow', 'port': 80, 'protocol': 'tcp'}, {'action': 'deny', 'port': 23, 'protocol': 'tcp'}]`

*(Обратите внимание: вывод — это строковое представление списка словарей Python).*

**Другой пример ввода (пустой список правил):**

`{"policy_name": "strict", "log_level": "warn", "rules": []}`

**Пример вывода для этого ввода:**

`[]`

*Эта задача покажет, как JSON-массивы преобразуются в списки Python и как получить доступ к этим спискам.*

### ***Теория***

***JSON-массивы и Списки Python***

В формате JSON данные могут быть упорядочены в виде **массивов** (arrays), которые заключаются в квадратные скобки `[]` и содержат значения, разделенные запятыми. Эти значения могут быть строками, числами, булевыми значениями, другими объектами или даже другими массивами.

При парсинге JSON с помощью модуля `json` в Python:
- JSON-объекты (`{...}`) преобразуются в словари Python (`dict`).
- JSON-массивы (`[...]`) преобразуются в **списки** Python (`list`)

```
import json

json_string = '{"policy_name": "default", "rules": [{"action": "allow", "port": 80}, {"action": "deny", "port": 23}]}'

# Парсим JSON
config_data = json.loads(json_string)

# config_data - это словарь:
# {'policy_name': 'default', 'rules': [{'action': 'allow', 'port': 80}, {'action': 'deny', 'port': 23}]}

# Получаем доступ к значению по ключу 'rules'
rules_list = config_data['rules']

# rules_list - это список Python:
# [{'action': 'allow', 'port': 80}, {'action': 'deny', 'port': 23}]

print(type(rules_list)) # Выведет: 
print(rules_list)
# Выведет строковое представление списка:
# [{'action': 'allow', 'port': 80}, {'action': 'deny', 'port': 23}]
```

***Доступ по ключу***

Как и в предыдущей задаче, доступ к значению (в данном случае, к списку правил) осуществляется по ключу (`"rules"`) в словаре, который мы получили после парсинга JSON.

### ***Решение*** 

```
# 1. Импортируйте модули json и sys
import json
import sys

# 2. Прочитайте всю строку JSON из стандартного ввода
json_string = sys.stdin.read()

# 3. Распарсите JSON-строку с помощью json.loads()
config_data = json.loads(json_string)

# 4. Получите список правил по ключу 'rules' из полученного словаря
rules_list = config_data['rules']

# 5. Выведите полученный список правил
print(rules_list)
```
