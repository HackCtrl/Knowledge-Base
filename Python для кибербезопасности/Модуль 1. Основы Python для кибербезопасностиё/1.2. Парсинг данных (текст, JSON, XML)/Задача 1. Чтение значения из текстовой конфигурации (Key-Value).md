Многие программы и скрипты используют простые текстовые файлы для хранения настроек. Часто используется формат "ключ-значение", где каждая строка содержит имя параметра (ключ) и его значение, разделенные, например, знаком равенства (`=`).

Представьте, что вы анализируете конфигурацию сетевого сервиса, и вам нужно узнать, какой порт он использует для прослушивания входящих соединений. Эта информация обычно хранится под ключом вроде `LISTEN_PORT`.

Ваша задача — прочитать многострочный текст конфигурации (поданный на стандартный ввод), найти строку с нужным ключом и извлечь его значение.

**Цель**

Написать программу на Python, которая:
1. Читает многострочный текст из **стандартного потока ввода** (stdin), представляющий собой конфигурацию.
2. Находит строку, которая начинается с ключа `"LISTEN_PORT"` (регистр важен).
3. Извлекает значение, идущее после знака `=` в этой строке. Учитывайте, что вокруг знака `=` могут быть пробелы, которые не являются частью значения.
4. Выводит на экран **только найденное значение** (без лишних пробелов по краям).
5. Если строка с ключом `LISTEN_PORT` не найдена, программа не должна ничего выводить.

**Пример ввода 1:**

`SERVER_NAME = webserver01`
# Порт для входящих соединений

`LISTEN_PORT = 8080`
`ADMIN_EMAIL = admin@example.com`

**Пример вывода 1:**

`8080`

**Пример ввода 2 (с пробелами):**

`LOG_LEVEL = INFO`
`LISTEN_PORT=443`
`MAX_CONNECTIONS = 100`

**Пример вывода 2:**

`443`

**Пример ввода 3 (ключ отсутствует):**

`HOST = 127.0.0.1`
`TIMEOUT = 30`

**Пример вывода 3:**

`(пусто, ничего не выводится)`

*Эта задача научит вас обрабатывать текстовые данные построчно, искать нужную информацию и очищать ее от лишних символов.*

### ***Теория***

Как и в прошлой задаче, для обработки многострочного ввода строка за строкой, мы можем итерировать напрямую по `sys.stdin` после импорта модуля `sys`

***Построчное чтение из `sys.stdin`***

```
import sys

for config_line in sys.stdin:
    # Обрабатываем каждую строку config_line
    # ...
```

***Поиск нужной строки: метод `.startswith(prefix)`***

Чтобы найти строку, которая начинается с нашего ключа (`"LISTEN_PORT"`), мы используем метод `.startswith()`

```
if config_line.startswith("LISTEN_PORT"):
```

***Разделение ключа и значения: метод `.split(separator, maxsplit)`***

Когда мы нашли нужную строку (например, `"LISTEN_PORT = 8080"`), нам нужно разделить ее на ключ и значение. Разделителем является знак `=`. Используем метод `.split('=')`

**Важно!** Мы хотим разделить строку только по **первому** знаку равенства, на случай если значение само содержит `=`. Для этого можно использовать необязательный второй аргумент `maxsplit`, который указывает максимальное количество разделений:

```
parts = config_line.split('=', 1) # Разделить максимум 1 раз
```

***Очистка значения от пробелов: метод `.strip()`***

Значение, которое мы получили (`parts[1]`), может содержать лишние пробелы в начале или конце (например, `' 8080'`). Чтобы удалить эти пробелы, используется метод строк `.strip()`

```
value_part = parts[1] # Например, ' 8080'
```

```
clean_value = value_part.strip() # clean_value станет '8080'
```

Метод `.strip()` удаляет пробельные символы (пробелы, табы, переводы строк) с обоих концов строки.

### ***Решение*** 

```
import sys

target_key = "LISTEN_PORT"

for config_line in sys.stdin:
    if config_line.startswith(target_key):
        parts = config_line.split('=', 1)
        if len(parts) == 2:
            value = parts[1].strip()
            print(value)
            break
```
