Многие API (Application Programming Interfaces), используемые для взаимодействия с системами безопасности, возвращают информацию в формате **JSON** (JavaScript Object Notation). Этот формат легко читается как людьми, так и машинами. Например, информация о пользователе, полученная от системы аутентификации, может прийти в виде JSON.

Ваша задача — научиться "разбирать" (парсить) строку в формате JSON и извлекать из нее конкретное значение.

**Цель**

Написать программу на Python, которая:
1. Получает на вход **одну строку**, содержащую данные о пользователе в формате JSON (через стандартный ввод).
2. Парсит эту JSON-строку.
3. Извлекает из полученной структуры данных значение, соответствующее ключу `"username"`.
4. Выводит на экран **только это значение** (имя пользователя).

**Пример ввода:**

`{"user_id": 123, "username": "jdoe", "groups": ["users", "beta-testers"]}`

**Пример вывода для этого ввода:**

`jdoe`

**Другой пример ввода:**

`{"username": "admin_sec", "email": "admin@internal.local", "user_id": 1, "is_active": true}`

**Пример вывода для этого ввода:**

`admin_sec`

*Эта задача познакомит вас со стандартной библиотекой Python для работы с JSON и основами извлечения данных из структурированного текста.*

### ***Теория*** 

***Формат JSON***

JSON представляет данные в виде пар "ключ-значение", похожих на словари в Python, а также массивов, похожих на списки Python. Ключи — это всегда строки в двойных кавычках. Значениями могут быть строки, числа, булевы значения (`true`, `false`), другие объекты (словари) или массивы (списки).

***Модуль `json` в Python***

Для работы с данными в формате JSON в Python есть встроенный модуль `json`

***Импорт модуля:***

`import json`

***Парсинг JSON-строки: Функция `json.loads(json_string)`***

Функция `json.loads()` (load string - загрузить строку) принимает строку, содержащую JSON, и преобразует ее в соответствующий объект Python (обычно словарь или список).

```
import json

json_string = '{"user_id": 123, "username": "jdoe", "is_active": true}'
# Парсим строку в объект Python (в данном случае - словарь)
user_data = json.loads(json_string)

print(user_data)
# Выведет: {'user_id': 123, 'username': 'jdoe', 'is_active': True}
# Обратите внимание: true стало True (Python bool)
```

***Словари в Python (`dict`)***

Результатом парсинга нашего JSON будет **словарь** Python. Словарь хранит пары "ключ-значение". Доступ к значению осуществляется по его ключу в квадратных скобках `[]`

***Пример доступа к значению в словаре:***

```
user_data = {'user_id': 123, 'username': 'jdoe', 'is_active': True}

# Получаем значение по ключу 'username'
name = user_data['username']
print(name) # Выведет: jdoe

# Получаем значение по ключу 'user_id'
uid = user_data['user_id']
print(uid) # Выведет: 123
```

Если попытаться получить доступ по ключу, которого нет в словаре, произойдет ошибка `KeyError`

***Чтение ввода и вывод***

Мы будем читать JSON-строку из `**sys.stdin**` (вероятно, она будет на одной строке, но `**sys.stdin.read()**` справится и с многострочным JSON), парсить ее с помощью `**json.loads()**`, извлекать значение по ключу `**"username"**` и выводить его с помощью `**print()**

### ***Решение***

```
# 1. Импортируйте модули json и sys
import json
import sys

# 2. Прочитайте всю строку JSON из стандартного ввода
json_string = sys.stdin.read()

# 3. Распарсите JSON-строку с помощью json.loads()
data = json.loads(json_string)

# 4. Получите значение по ключу 'username' из полученного словаря
username = data['username']

# 5. Выведите полученное значение
print(username)
```
