Веб-серверы, такие как Nginx, записывают информацию о каждом запросе в лог-файлы. Анализ этих логов критически важен для отслеживания посещаемости, поиска ошибок и обнаружения подозрительной активности, например, попыток взлома или DDoS-атак.

Стандартный формат лога Nginx обычно начинается с IP-адреса клиента, сделавшего запрос. Ваша задача — извлечь этот IP-адрес из одной строки лога.

**Цель**

Написать программу на Python, которая:
1. Получает на вход **одну строку** — запись из лога Nginx (через стандартный ввод).
2. Извлекает из этой строки самую первую часть — IP-адрес клиента (он идет до первого пробела).
3. Выводит на экран **только этот IP-адрес**.

**Пример ввода:**

`192.168.5.12 - - [11/Oct/2023:14:25:01 +0300] "GET /images/logo.png HTTP/1.1" 200 1578 "http://example.com/" "Mozilla/5.0 ..."`

**Пример вывода для этого ввода:**

`192.168.5.12`

**Другой пример ввода:**

`203.0.113.5 - user1 [11/Oct/2023:14:26:30 +0300] "POST /login HTTP/1.1" 401 50 "-" "curl/7.68.0"`

**Пример вывода для этого ввода:**

`203.0.113.5`

*Эта задача научит вас разбивать строки на части — основному методу парсинга простого текстового формата.*

### ***Теория*** 

**`.split()`** - чтобы разделить строку на отдельные слова или фрагменты по определенному разделителю, используется метод строк 

***Как он работает:*** 
- Вызывается для строки: `строка.split(разделитель)`
- Возвращает **список** (`list`) строк, полученных после разбиения
- **Если разделитель не указан (вызов `строка.split()`):** строка разбивается по **любым пробельным символам** (пробелы, табы, переводы строк), при этом пустые строки в результате игнорируются. Это очень удобно для форматов, где части разделены пробелами
- Если разделитель указан (например, `строка.split('-')`), разбиение происходит именно по этому символу

***Пример***

```
nginx_log = '192.168.1.1 - - [дата] "запрос" ...'

parts = nginx_log.split() # Разбиваем по пробелам

print(parts)
```

***Пример вывода***

```
['192.168.1.1', '-', '-', '[дата]', '"запрос"', ...]
```

***Доступ к элементам списка***

Результат `.split()` — это список. Чтобы получить доступ к отдельным элементам списка, используются индексы в квадратных скобках `[]`. Нумерация индексов начинается с **0**.

- `список[0]` — первый элемент
- `список[1]` — второй элемент
- и т.д.

В нашем примере `parts[0]` будет содержать строку `'192.168.1.1'`, так как это первый элемент списка, полученного после разбиения строки лога по пробелам

### ***Решение*** 

```
# 1. Прочитайте строку лога из стандартного ввода
log_line = input()

# 2. Разбейте строку на части с помощью метода .split()
#    Вспомните, как получить первую часть (IP-адрес).
ip = log_line.split()

# 3. Выведите полученный IP-адрес
print(ip[0])
```
