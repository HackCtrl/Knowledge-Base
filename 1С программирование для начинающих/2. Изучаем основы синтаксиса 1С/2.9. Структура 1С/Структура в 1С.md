***Структура*** - это таблица с двумя колонками. Первая колонка называется ключ, а вторая значение. Ключ может быть только строковым типом данных и должен выполнять требования к наименованию переменных, а вот значение может быть любым 

***Ключ должен соответствовать правилам, установленным для идентификаторов:*** 
- Первым символом ключа должна быть буква или символ подчеркивания 
- Каждый из последующих символов может быть буквой, цифрой или символом подчеркивания. Так же нельзя использовать пробелы в ключе 

Допустим у нас с вами есть информация об автомобиле, его марка, модель, цвет, количество лошадиных сил и стоимости.

Чтобы записать эту информацию в 1С мы можем использовать переменные, это будет выглядеть следующим образом:

```
Модель = "GTR";
Марка = "Nissan";
Цвет = "Желтый";
ЛошадиныхСил = 250;
Стоимость = 1000000;
```

Чтобы создать структуру, нам необходимо так же создать переменную, которую мы назначим структурой. Выглядит это следующим образом:

```
СтруктураАвтомобиль = Новый Структура;
```

```
СтруктураАвтомобиль = Новый Структура; 

СтруктураАвтомобиль.Вставить("Модель", "GTR"); СтруктураАвтомобиль.Вставить("Марка", "Nissan"); СтруктураАвтомобиль.Вставить("Цвет", "Желтый"); СтруктураАвтомобиль.Вставить("ЛошадиныхСил", 250); СтруктураАвтомобиль.Вставить("Стоимость", 1000000);
```

*Ключ в структуре 1С уникален в рамках одной структуры! То есть нельзя создать несколько элементов с одинаковым ключем в рамках одной структуры*  

Так же познакомимся с **фиксированной структурой**, в которой мы сразу задаем **ключи** нашей структуры, выглядит она следующим образом:

```
СтруктураАвтомобиль = Новый Структура("Модель, Марка, Цвет, ЛошадиныхСил, Стоимость"); 

СтруктураАвтомобиль.Модель = "GTR";
СтруктураАвтомобиль.Марка = "Nissan";
СтруктураАвтомобиль.Цвет = "Желтый";
СтруктураАвтомобиль.ЛошадиныхСил = 250;
СтруктураАвтомобиль.Стоимость = 1000000;


ФиксированнаяСтруктураАвтомобилей = Новый ФиксированнаяСтруктура(СтруктураАвтомобиль);
```

Такая же картина и работает для получения значений нашей структуры. Например чтобы получить значение марки нашей структуры, достаточно написать:

```
МаркаАвто = СтруктураАвтомобиль.Марка;
```

Так же, для получения значений, как и для их заполнения, возможно указать следующую конструкцию:

```
//Заполнение:

СтруктураАвтомобиль["Марка"] = "Nissan";

//Получение:

МаркаАвто = СтруктураАвтомобиль["Марка"];

//Альтернативное получение:

МаркаАвто = СтруктураАвтомобиль.Марка;
```

Давайте теперь на практике попробуем поработать со структурой, например нам нужно вывести в сообщении все значения нашей структуры, и тут нам поможет вид циклов **Для каждого**, который мы немного затронули в уроке про циклы.

```
Сообщение = Новый СообщениеПользователю;
Для Каждого ЭлементСтруктуры Из СтруктураАвтомобиль Цикл
	Сообщение.Текст = ЭлементСтруктуры.Значение;
	Сообщение.Сообщить();
КонецЦикла;
```
