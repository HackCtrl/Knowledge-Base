# 3. Лекция. Часть 3

```sql
select *
from coderun c
right join users u
on c.user_id = u.id
join company c2
on coalesce(u.company_id, 1) = c2.id
```
*Здесь мы по базе соединяем две таблицы и к наим присоеденилась информация про всех пользователей, которая решали/не решали задачи* 

```sql
select *
from coderun c
join users u
on c.user_id = u.id and created_at >= date_joined
```
```sql
select *
from coderun c
right join users u
on c.user_id = u.id and created_at <= date_joined
```
```sql
select *
from coderun c
right join users u
on (c.user_id = u.id and created_at < date_joined) or (c.user_id = u.id and created_at <= date_joined)
```
