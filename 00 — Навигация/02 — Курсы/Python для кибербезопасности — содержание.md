# Python для кибербезопасности — содержание

Практический курс по применению Python к базовым задачам информационной безопасности.

> [!note] Статус курса
> Курс перенесён в архив, исключён из активного учебного плана и не учитывается в текущей нагрузке. Конспекты и выполненные задания сохранены как справочные материалы и доказательства ранее выполненной учебной практики. Минимальный скриптинг используется только как встроенный навык внутри системного администрирования и кибербезопасности.
