# Структура хранилища

## Корневые разделы

| Папка | Назначение |
|---|---|
| `00 — Навигация` | Главная, карты направлений, страницы курсов и управление базой |
| `10 — База знаний` | Обобщённые профессиональные понятия и технологии |
| `20 — Обучение` | Активные и архивные курсы с исходной последовательностью |
| `30 — Практика и кейсы` | Лабораторные работы, задания, решения и учебные кейсы |
| `40 — Работа` | Публично безопасные профессиональные материалы |
| `50 — Проекты` | Карты DTEK Core, CyberWhale и других проектов |
| `90 — Приватное` | Локальные конфиденциальные материалы; каталог исключён из Git |
| `99 — Шаблоны` | Шаблоны новых заметок |

## Логика движения знания

[[Обучение]] → конспект темы → [[Практика и кейсы]] → собственный вывод → [[База знаний]] → профессиональное применение в [[Работа|работе]] или [[Проекты|проекте]].

## Где создавать новые материалы

- Конспект урока — внутри соответствующего курса в `20 — Обучение`.
- Самостоятельная лабораторная — в `30 — Практика и кейсы`.
- Обобщение понятия — в тематической подпапке `10 — База знаний`.
- Безопасная рабочая инструкция — в `40 — Работа`.
- Документация проекта — в `50 — Проекты`.
- Материал с реальными внутренними данными — только в `90 — Приватное` с последующим переносом секретов в менеджер паролей.

## Навигационный принцип

С [[Главная|Главной]] каждый основной раздел доступен за один переход, карты направлений — за один переход, конкретный курс или практика — не более чем за два–три перехода.

## Ограничения

- Не удалять исходные материалы без ручной проверки.
- Не смешивать учебные примеры с реальными рабочими данными.
- Не создавать вторую обобщённую заметку, если понятие уже описано.
- Не публиковать `90 — Приватное` и не добавлять ссылки на него в GitHub README.
