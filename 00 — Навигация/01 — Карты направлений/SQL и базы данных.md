# SQL и базы данных

Направление охватывает получение, фильтрацию, преобразование и соединение данных. Эти навыки применимы к аналитике, журналам событий и прикладным системам.

## Ключевые темы

- SELECT и FROM;
- WHERE и операторы фильтрации;
- сортировка;
- текстовые функции;
- дата и время;
- JOIN;
- подключение к базе данных.

## Профессиональные задачи

- поиск записей по условиям;
- объединение данных из нескольких таблиц;
- подготовка выборок для анализа;
- проверка данных прикладных систем.
