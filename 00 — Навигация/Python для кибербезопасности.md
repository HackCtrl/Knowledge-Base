# Python для кибербезопасности

Python используется для автоматизации повторяемых задач, обработки журналов и разбора структурированных данных.

## Ключевые темы

- переменные, условия и строки;
- работа с IP-адресами и портами;
- чтение текстовых журналов;
- JSON и XML;
- маскирование данных;
- простые проверки событий безопасности.
