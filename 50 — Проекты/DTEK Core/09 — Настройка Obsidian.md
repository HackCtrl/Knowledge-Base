2. **Dataview** — установлен; автоматическая сводка добавлена в реестр спринтов.

Все представления сохраняют читаемый Markdown. Плагины устанавливаются и проверяются по одному, чтобы рабочее пространство оставалось устойчивым.

## Как создать документ из шаблона

1. Откройте палитру команд `Cmd + P`.
2. Выберите `Templater: Create new note from template`.
3. Выберите нужный русский шаблон.
4. Ответьте на короткие вопросы. Имя файла, дата и свойства будут заполнены автоматически.

Доступны шаблоны Спринта, задачи, ошибки, идеи, решения, интервью, еженедельного обзора и итогового отчёта по Спринту.

Автоматический запуск, системные команды и пользовательские скрипты отключены. Шаблоны запускаются только вручную.

## Календарь и обзоры

Calendar является общим для всего Vault и не перенаправляет ежедневные заметки внутрь DTEK Core. Еженедельные обзоры проекта создаются через Templater и автоматически появляются в [[50 — Проекты/DTEK Core/Обзоры/00 — Еженедельные обзоры|журнале обзоров]].

## Быстрый доступ

В стандартной панели закладок Obsidian создана группа `DTEK Core`. В ней находятся главная панель, центр задач, доска разработки, Roadmap, обязательный этап безопасности, журнал обзоров и визуальные карты.

Чтобы открыть закладки, используйте значок закладки рядом с поиском в левом верхнем углу. Через `Cmd + P` ищите команду по слову `Закладки`: название системной команды зависит от языка интерфейса Obsidian.
