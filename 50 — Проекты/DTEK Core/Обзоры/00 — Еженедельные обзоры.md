# Еженедельные обзоры

Один обзор создаётся в конце активной недели по [[50 — Проекты/DTEK Core/Шаблоны/Еженедельный обзор|шаблону]]. Реестр ниже формируется автоматически по свойствам созданных заметок.

```dataview
TABLE WITHOUT ID
  link(file.path, file.name) AS "Обзор",
  дата AS "Дата",
  статус AS "Статус",
  dateformat(file.mtime, "dd.MM.yyyy HH:mm") AS "Обновлено"
FROM "50 — Проекты/DTEK Core"
WHERE тип = "еженедельный обзор"
SORT дата DESC
```

## Создать новый обзор

1. Нажмите `Cmd + P`.
2. Выберите `Templater: Create new note from template`.
3. Выберите `Еженедельный обзор`.
4. Заметка автоматически получит дату, правильное имя и будет перемещена в папку обзоров.
