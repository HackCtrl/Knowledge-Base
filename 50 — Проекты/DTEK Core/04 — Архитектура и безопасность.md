# Архитектура и безопасность

## Текущий среда выполнения

Next.js App Router, TypeScript strict, Supabase Auth, PostgreSQL, RLS/RBAC и Vercel. Текущая production schema заканчивается миграцией 019.

## Ключевые границы

- изоляция организаций и будущих рабочих пространств;
- Server Action authorization и input validation;
- RLS как обязательная DB-граница;
- service role только на сервере;
- коннектор не пишет напрямую в Objects, Risks или Trust Score;
- Personal/Home данные требуют согласия, минимизации и удаления;
- никакого произвольного сканирования или несанкционированного OSINT.

## Главный технический долг

До расширения платформы закрыть SEC-01–04 и STAB-01–05 из обязательного контрольный этап.
