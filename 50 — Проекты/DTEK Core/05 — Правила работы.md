# Как мы ведём проект

## Роли

| Роль | Ответственность |
|---|---|
| Владелец проекта | Приоритеты, практические проверки ИБ, ручная приёмка, интервью, анализ рисков и GO/NO-GO |
| Codex | Объяснение и постановка практики, код, автоматические проверки, технический анализ, документация, commit и push |
| Совместная работа | Критерии приёмки, разбор доказательств, решения, Roadmap и итоговая оценка |
| Obsidian | Понятные статусы, доски, идеи, решения и отчётность |
| Git-репозиторий | Код и технические источники истины |

## Цикл одной задачи

```text
Идея → Готово к работе → Анализ → Разработка → Проверки → Ручная приёмка → Commit/Push → Завершено
```

## Цикл практической работы владельца

```text
Простое объяснение → Карточка практики → Самостоятельная проверка
→ Доказательство → Разбор с Codex → Техническая часть → Совместный вывод
```

Рабочее пространство: [[50 — Проекты/DTEK Core/11 — Работа владельца и практика ИБ|Работа владельца и практика ИБ]].

## Перед началом

1. У задачи есть Task ID и Спринт.
2. Понятны цель, зависимости, границы и критерии готовности.
3. Проверены архитектура, безопасность и пользовательские изменения.
4. Для БД подтверждены migration parity и backup.

## После завершения

1. Выполнены type-check, lint, build и релевантные тесты.
2. Обновлены Спринт, доски, документация и риски.
3. Есть Conventional Commit и подтверждённый push.
4. Следующая задача не начинается автоматически.
