TCP/IP поддерживает адреса классов A, B, C. Класс адреса определяет, какие биты относятся к идентификатору сети, а какие - к идентификатору узла. Также он определяет максимальное возможное количество узлов в сети. Иначе говоря, чтобы упростить классификацию различных сетей с учетом их размера, IP-адреса разделили на классы 

![[Pasted image 20260818134003.png]]
### ***Класс A*** 

**Пример адреса класса A:** 10.1.2.3. Здесь «10» — идентификатор сети, а «1.2.3» — идентификатор хоста в этой сети

Это класс, предназначенный для очень крупных сетей с большим количеством хостов
### ***Класс B*** 

**Пример сети класса B:** **172.16.0.0 — 172.31.255.255**

Gредназначен для сетей среднего размера — например, для университетов, крупных компаний или филиалов
### ***Класс C*** 

**192.168.1.0**

Изначально использовался для небольших локальных сетей
### ***Клаcc D*** 

Это специализированный диапазон IP-адресов, зарезервированный для **многоадресной (групповой) рассылки** (multicast). Такие адреса позволяют отправлять один пакет данных одновременно нескольким получателям, что эффективно для потоковой передачи мультимедиа, видеоконференций, онлайн-игр и других приложений, где нужно распределять данные по нескольким получателям в разных сетях.
