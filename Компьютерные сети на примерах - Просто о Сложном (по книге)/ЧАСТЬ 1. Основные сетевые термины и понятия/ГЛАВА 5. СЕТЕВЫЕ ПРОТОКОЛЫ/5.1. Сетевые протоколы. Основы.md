***Сетевой протокол*** - набор правил, позволяющий осуществлять обмен данными между составляющими устройствами, например, между двумя сетевыми картами. На языке протоколов сетевые компьютеры разговаривают 
### ***TCP/IP***

***Стек протокола TCP/IP*** - это два протокола, являющийся основой связи в сети интернет. Протокол TCP разбивает передаваемую информацию на порции (пакеты) и нумерует их. С помощью протокола IP все пакеты передаются получателю. Дальше с помощью протокола TCP проверяется, все ли пакеты получены. При получении всей порции TCP располагает их в нужном порядке и собирает в единое целое. В сети интернет используются две версии этого протокола: 
- IPv4 (адрес длиной 32 байта - 4 октета по 4 байта)
- IPv6 (128 разрядные адреса)
### ***ARP*** 

***ARP (Address Resolution Protocol)*** - протокол преобразования адресов, который позволяет автоматически получить MAC-адрес по известным IP-адресам 
### ***DHCP-протокол*** 

***DHCP (Dynamic Host Configuration Protocol)*** - автоматизирует процесс назначения IP-адресов всем узлам сети 
### ***HTTP-протокол*** 

Служит для передачи гипертекста, то есть пересылает Web-страницы с одного ПК на другой. Основой HTTP является технология (клиент-сервер), то есть предполагается существование потребителей (клиентов), которые инициируют соединение и посылают запрос, и поставщиков (серверов), которые ожидают соединения для получения запроса
### ***FTP-протокол*** 

***FTP*** - нужен для передачи файлов со специального файлового сервера на компьютер пользователя
### ***POP-протокол*** 

***POP*** - стандартный протокол получения почтового соединения. Серверы POP обрабатывают входящую почту, а протокол POP предназначен для обработки запросов на получение почты от клиентских почтовых программ 
### ***SMTP-протокол*** 

***SMTP*** - протокол, который задает набор правил для отправки почты 
### ***IP-адрес по протоколу IPv4*** 

***IP-адрес*** - сетевой (программный) адрес узла в компьютерной сети, построенный по протоколу IP
