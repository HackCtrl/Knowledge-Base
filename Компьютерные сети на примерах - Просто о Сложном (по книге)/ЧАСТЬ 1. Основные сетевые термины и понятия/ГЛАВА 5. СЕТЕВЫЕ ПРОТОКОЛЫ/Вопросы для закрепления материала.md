### ***Что такое стек протоколов ?*** 

Набор правил, позволяющий осуществлять обмен данными в сети 
### ***Какие наборы протоколов вы знаете ?*** 

TCP/IP, OSI, 
### ***Какой стек протоколов сегодня наиболее популярнее ? Почему ?*** 

TCP/IP. Универсальная, Надежная передача данных, Масштабируемость, Гибкость
### ***Какие уровни модели OSI поддерживаются в стеке протоколов TCP/IP ?*** 

Прикладной и транспортный 
### ***Почему протоколов много ?*** 

Каждый отвечает за свой функционал

## ***Практические задачи и тесты*** 

### ***Что такое сетевой протокол, дайте определение ?*** 

Набор правил, позволяющий осуществлять обмен данными между составляющими сеть устройствами 
### ***Какой из сетевых протоколов является основным в сети Интернет ?*** 

TCP/IP 
### ***Какой из сетевых протоколов адресует наибольшее пространство адресов ?*** 

IPv6
### ***Отметить не верные ответы*** 

Протокол DHCP используется для получения IP-адресов по имени хоста (компьютера или устройства)
### ***Сколько протоколов содержит стек протоколов TCP/IP ?*** 

Четыре 
### ***Что лежит в основе протокола HTTP ?*** 

Технология клиент-сервер 
### ***Где используют FTP протокол ?*** 

Для передачи файлов со специального файлового сервера на компьютер пользователя 
### ***Какой из протоколов задает набор правил для отправки электронной почты ?*** 

SMTP протокол 
### ***Найти неверное утверждение*** 

Протокол Интернета IPv6 использует 64-разрядные адреса 
### ***Какой из ответов ниже не содержит название протокола ?*** 

URL
