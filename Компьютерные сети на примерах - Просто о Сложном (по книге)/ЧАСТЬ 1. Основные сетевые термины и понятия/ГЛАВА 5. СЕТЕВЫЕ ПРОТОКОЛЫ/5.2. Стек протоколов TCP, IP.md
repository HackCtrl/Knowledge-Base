### 1. ***Физический уровень стека TCP/IP***

На физическом уровне TCP/IP поддерживает работу с основными технологиями локальных сетей - Ethernet, Token Ring, WI-FI, Bluetooth и т.д 
### 2. ***Сетевой уровень стека TCP/IP*** 

- **Протокол ARP** - отвечает за преобразование сетевых IP-адресов в аппаратные MAC-адреса 
- **Протокол RARP** - осуществляет обратное преобразование MAC-адреса в IP-адрес 
- **Протокол ICMP** - использует для передачи сообщений об ошибки (ping, tracert)
- **Протокол IP** - отвечает за доставку IP дейтаграмм, обеспечивая передачу пакета от одной сети в другую 
### 3. ***Транспортный уровень OSI*** 

- Протокол TCP 
- Протокол UDP 
### 4. ***Прикладной уровень стека TCP/IP***

- **NTP** - протокол сетевого времени, используется для синхронизации системных часов компьютеров в сетях 
- **DNS** - служба доменных имен, для преобразование понятных для человека имен в IP 
- **NetBIOS** - используется для преобразования NetBIOS имен компьютеров в IP-адреса 
- **LDAP** - протокол доступа к каталогу, используется для работы с различными сетевыми каталогами 
- **RPC** - вызов удаленной процедуры, используется для работы с сетевыми службами в сетях Майкрософт 
- **Telnet** - протокол для обеспечения терминального доступа к удаленным компьютерам 
- **FTP** - протокол передачи данных, используется для надежной передачи данных между клиентом и сервером 
- **Kopher** - протокол используется для доступа к текстовым информационным ресурсам на удаленном сервере 
- **HTTP** - протокол передачи гипертекста, описывает каким способ нужно предоставлять данные на веб-серверах, как к ним обращаться с помощью веб-браузера 
- **NNTP** - протокол передачи сетевых новостей в системных телеконференций
- **SMTP** - протокол передачи почты 
- **POP3** - протокол, использующий почтовым клиентам для подключения к своему почтовому ящику на сервере и считывания сообщений 
- **IMAP** - протокол доступа к электронным сообщениям 
- **SSL** - протокол, обеспечивающий согласование алгоритмов обмена ключами шифрования. Используется для защиты данных при их пересылке по сетям
