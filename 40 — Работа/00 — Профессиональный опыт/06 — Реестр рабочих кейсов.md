## Поля подробного кейса

Для нового подтверждённого случая использовать следующую структуру:

| Поле | Требование |
|---|---|
| Название | Короткое обезличенное описание задачи |
| Организация | Название только при разрешении на публикацию |
| Дата | Указывать только если известна и безопасна |
| Категория | Поддержка, сеть, 1С, мониторинг, оборудование, доступ или документация |
| Исходная проблема | Без имён, адресов, номеров объектов и финансовых данных |
| Симптомы | Только необходимые технические признаки |
| Диагностика | Последовательность безопасных проверок |
| Мои действия | Фактические действия и границы полномочий |
| Инструменты | Продукты можно указывать только при допустимости публикации |
| Результат | Только подтверждённое восстановление или подготовленная среда без вымышленных показателей |
| Чему научился | Собственный технический вывод |
| Связанные компетенции | Ссылка на [[05 — Карта рабочих компетенций]] |
| Подтверждающие материалы | Приватная ссылка без копирования содержимого |
| Конфиденциальность | Публичное, после проверки, только для себя или чувствительное |
| Портфолио | Да, после проверки или нет |
| Что обезличить | Имена, адреса, реквизиты, конфигурации, скриншоты и внутренние названия |

## Правило публикации

1. Создать приватную карточку без секретов и персональных данных.
2. Проверить фактическую точность и границы собственных действий.
3. Удалить инфраструктурные параметры и бизнес-данные.
4. Подтвердить возможность упоминания организации и продукта.
5. Только после этого подготовить краткую публичную версию.
